# シリーズ9：位相的データ解析（TDA）─ p5.js コード集

データの「形」を数える。点群から穴を見つけ、パーシステント・バーコードで記録する TDA（Topological Data Analysis）を体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series9/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 多くのスケッチは一番下に「TDA の道具」（リップス複体とパーシステント・ホモロジーの計算）があります。**一番下まで全部コピー**してください

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 画面が固まる | 点の数を減らす（三角形の数は点の数の 3 乗で増える）。`maxR` を小さく |
| `persistence is not defined` | 一番下の「TDA の道具」までコピーできていない → 全部コピーし直す |
| 穴が思ったように出ない | ノイズを減らす、点を増やす。「長い棒」だけを数える（しきい値を上げる） |
| 音が出ない・マイクが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

「TDA の道具」は Z2 係数の標準的な列簡約アルゴリズムで、H0 と H1（塊と穴）を計算します。教育用の簡易実装です（数十点が目安）。
