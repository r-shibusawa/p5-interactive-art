# シリーズ52：心理物理学 ─ p5.js コード集

「どれだけ変われば、違いに気づく？」「2 倍の明るさは、2 倍に見える？」― 感覚の大きさを数で測るのが心理物理学です。ウェーバー・フェヒナー・スティーヴンスの法則から、恒常法・上下法・信号検出理論・強制選択という測り方、コントラスト感度・色の弁別・反応時間（ヒックとフィッツ）、等ラウドネス・音の高さ・マスキング、音と光の同時性まで、**自分が観察者になる実験**をして、自分のデータに関数を本当に当てはめるワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series52/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「心理物理の道具」（乱数・正規分布・ロジスティック関数の最尤法・直線の当てはめ・上下法など）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（11〜14）は**音量を小さめから**（ヘッドホンは特に注意）。📷 カメラ（15）はアドレスバーで許可する
5. 00〜14 は **O キーで「シミュレーション観察者」**（本当の値がわかっているコンピュータの観察者）が答える。自分のデータと見比べたり、当てはめが正しく動くかを確かめたりできる

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `fitLogistic is not defined` / `makeStair is not defined` | 一番下の「心理物理の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す。スペースで開始するスケッチが多い |
| 画面左下の「自己テスト」が ✗ になる | 道具の中の式を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 「データ不足」と出て曲線が出ない | 当てはめには 2 段階以上・数試行以上のデータがいる。もう少し続けるか O で確かめる |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |
| 音が大きすぎる | すぐに端末の音量を下げる。どのスケッチも全体の音量は 0.2 以下（`MASTER`）。上げないこと |

ロジスティック関数は最尤法（ニュートン法 = フィッシャーのスコア法）、d′ の z は正規分布の累積分布 Φ を二分法で逆に解いて（割合は 1/(2N) で補正）、直線・放物線・楕円は最小二乗法で、すべて画面の数字のとおりに計算しています。各スケッチは起動時に自己テストで、種つきの乱数で動かしたシミュレーション観察者から本当の値（PSE と JND、70.7% 点、d′ と c、べき指数、ヒック・フィッツの傾き、臨界帯域、弁別楕円など）を復元できるか、そして Φ(0) = 0.5、z(Φ(1)) = 1、Pc(d′ = 0) = 0.5、sRGB の白 → Lab = (100, 0, 0)、同じ色の ΔE = 0、log₂(300/20 + 1) = 4 などの手で計算できる値と照合しています。光は 1 試行に 1 回だけで、速い点滅（3 Hz 以上）はありません。測った値は画面や部屋、端末・ヘッドホンによって変わります（形の傾向を見るための実験です）。
