# シリーズ70：隠れマルコフモデル ─ p5.js コード集

**見えない状態がマルコフ連鎖で動き、見えるのはそこから出た観測だけ。** その「見えないもの」を推し量る ― 隠れマルコフモデル（HMM）のワークショップ（110分）のコード集です。かさだけを見て天気を当てる生成モデルから始めて、尤度と前向きアルゴリズム、フィルタリング、ビタビの最尤経路、平滑化と予測、バウム-ウェルチ（EM）による学習、アンダーフローとスケーリング、状態数の選び方、正規分布を出す HMM、左から右への HMM によるジェスチャ認識、滞在時間と隠れセミマルコフモデル、ペア HMM と配列アラインメント、品詞タグ付け、DNA の領域さがし、そして音とカメラまで、どれも**アルゴリズムをゼロから実装して、短い列では N^T 本の道の総当たりと答えが一致することを確かめる**スケッチです。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series70/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「HMM の道具」（サンプリング、前向き・後ろ向き（そのまま・スケーリング・対数）、ビタビ、平滑化、バウム-ウェルチ、総当たり、グラフを描く道具、種つきの乱数、自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. 記号：モデル `m = { p0, tr, em }` ＝ はじめの分布 π、遷移行列 A（`tr[i][j]` = 状態 i の次に j、各行の合計 = 1）、出力行列 B（`em[j][k]` = 状態 j が記号 k を出す）。α = 前向き、β = 後ろ向き、γ_t(i) = P(z_t = i | 観測)、ξ_t(i, j) = P(z_t = i, z_{t+1} = j | 観測)、δ = ビタビ
6. 文字を入力するスケッチ：11 は A・C・G・T のキーが文字の入力（操作は矢印・Tab・Backspace・R）、12 は文字キーとスペースがすべて入力（操作は ↑↓・Tab・Backspace・Esc）。14 は A S D F G H J K が鍵盤
7. 学習（05・07・08・13）は 1 フレームに少しずつ進めるので、画面は止まりません

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `fwdScaled is not defined` / `seedRng is not defined` | 一番下の「HMM の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 文字を打つと勝手に操作される／操作キーが効かない | 11 は A・C・G・T、12 は文字キーとスペースがすべて入力になる。操作は矢印・Tab・Backspace・Esc（11 は R も）。14 は A S D F G H J K が鍵盤 |
| 確率が NaN・0 になる | 行列の行の合計が 1 か確かめる。長い列でそのまま掛け算すると 0 になる（06）→ スケーリングつき `fwdScaled` か対数の `fwdLog` を使う。log 0 は −∞ のまま扱う |
| 学習（05・07・08・13）の結果が毎回ちがう／本物と合わない | 出発点によって別の山に登る（N や スペースでやり直す）。状態の番号は本物と入れかわることがある（ラベルの入れかえ） |
| 09 で判定がおかしい | 描きはじめの位置と向きもジェスチャのうち（丸は上から時計回り、Z は左上から）。自分の描き方を 1〜4 → T で教える。C で元にもどす |
| 画面右下の「自己テスト」が ✗ になる | モデルの数字や道具を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもマウスの動きで動く。C で切りかえ） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

アルゴリズムはすべてゼロから実装しています：(π, A, B) からのサンプリング、前向き・後ろ向き（そのまま、毎時刻の正規化 c_t つき、log-sum-exp による対数版）、予測 → 更新のフィルタと k 歩先の予測、平滑化 γ と ξ、固定ラグ平滑化、戻り矢印つきの対数ビタビと事後復号、バウム-ウェルチ（複数の観測列、出発点のやり直し、ラベルの入れかえの並べかえ）、BIC・AIC と検証データの対数尤度、正規分布を出す HMM の EM（分散の下限つき）、左から右への（バキス型）HMM と 8 方向の記号化、滞在時間を明示した隠れセミマルコフモデルのサンプリングと前向き、3 状態のペア HMM のビタビ・前向き・後ろ向きとアフィンギャップの Needleman–Wunsch、数えて作る品詞タグ付け（加算スムージング、知らない単語の扱い）、2 状態の DNA の領域分け。各スケッチは起動時に自己テストで、行の合計 = 1、サンプルの割合 ≈ A・B、前向き = 後ろ向き = N^T 本の総当たり、フィルタ・平滑化・ξ = 総当たりの事後確率、ビタビ = 総当たりの最大、事後復号の道が確率 0 になる例、そのまま = スケーリング = 対数（T = 20）と T = 5000 でのアンダーフロー、バウム-ウェルチの対数尤度が下がらないこと、BIC が本当の状態数で最小、正規分布の平均の復元としきい値法との比較、学習後も遷移行列が上三角、滞在時間の平均 = 1/(1 − a_ii)、HSMM の前向き = 総当たり = 状態を広げた HMM、ペア HMM のビタビ = Needleman–Wunsch の点数 + 定数、あいまいな単語の品詞、窓の方法より高い当たりの割合、などを照合しています。マルコフ連鎖（遷移行列・定常分布）はシリーズ 65、前向き後ろ向きの入門はシリーズ 65 の 09、マックスプラスとしてのビタビはシリーズ 59 の 13、カルマンフィルタ・粒子フィルタはシリーズ 21 の 10・11、EM はシリーズ 61 の 08 とシリーズ 67 の 09、編集距離はシリーズ 12 の 04、オートマトンはシリーズ 66、マルコフ決定過程はシリーズ 63 で扱っています。
