## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series20/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 多くのスケッチは一番下に「道具」（グラフを描く関数、複素数や行列の計算）があります。**一番下まで全部コピー**してください

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 値が発散する・画面から消える | ゲイン（Kp など）を下げる。`dt` を小さくする、または 1 フレームの計算を細かく分ける |
| `drawPlot is not defined` | 一番下の「道具」までコピーできていない → 全部コピーし直す |
| 矢印キーが効かない | キャンバスを1回クリックしてから押す。`key === LEFT_ARROW` の書き方を確認 |
| 音が出ない・マイクが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

シミュレーションは固定の時間刻み（dt = 1/60 秒）のオイラー法です。教育用の簡易実装なので、ゲインを極端にすると数値的に不安定になることがあります（その場合は分割数を増やす）。
