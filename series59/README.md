# シリーズ59：マックスプラス代数 ─ p5.js コード集

「足し算を max に、掛け算を + に」置きかえると、待ち合わせ・時刻表・生産ライン・最短経路が「1 次式」と「行列の計算」になる ― マックスプラス代数を**計算の道具として**使うワークショップ（110分）のコード集です。待ち合わせの算数と半環のルールから始めて、行列の積と最長経路、推移的閉包 A*、引き算のない方程式の解き方（残余）、列車ダイヤと生産ライン、固有値＝サイクル時間（カープのアルゴリズム）、過渡と周期性、遅延の伝わり方、時間付きペトリネット、min-plus と最短経路、ビタビと「脱量子化」まで、どれも**本当に計算した**シミュレーションです。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「マックスプラスの道具」（⊕・⊗、行列の積、A*、カープのアルゴリズム、自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. 記号：a ⊕ b = max(a, b)、a ⊗ b = a + b、ε = −∞（「ゼロ」= 起きない・制約なし）、e = 0（「いち」= 待ち時間なし）。画面では ε を「ε」と表示します

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `mpMul is not defined` / `karp is not defined` | 一番下の「マックスプラスの道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 画面右下の「自己テスト」が ✗ になる | 道具の中の式を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 数字が NaN や −Infinity になる | ε（−∞）どうしを普通の + で足した。⊗ は必ず `mpMul` を使う（ε があれば ε を返す） |
| 「正の回路」「デッドロック」と出て止まる | 04 は締め切り W を大きく、11 はトークン 0 の回路にトークンを足す（そういう条件では本当に解がない） |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

⊕ と ⊗ は ε = −∞ をはっきり別あつかいして（`mpMul` は ε があれば ε、残余では a_ij = ε の行を飛ばす）、NaN が一度も出ないように作っています。行列の積・べき・A*（正の回路の検出つき）・残余 x_j = min_i (b_i − a_ij)・カープのアルゴリズム・臨界グラフと固有ベクトル（(A − λ)* の列）・べき乗法による過渡と周期・巡回性はすべてゼロから実装しています。固有値や周期を調べるグラフは必ず強連結（ランダムなグラフにはハミルトン閉路を入れる）で、強連結でない例は「既約でない」と表示します。各スケッチは起動時に自己テストで、半環の法則（ε 入り）、(A^{⊗k})_ij = 全部の道の総当たり、A* = フロイド-ワーシャル法と正の回路の検出、残余が A ⊗ x ≤ b の最大の解であること、カープの λ = 全回路の平均の最大、A ⊗ v = λ ⊗ v、見える周期が巡回性の約数、時刻表の漸化式 = 条件を 1 つずつたどった時刻、ペトリネットのトークンのシミュレーション = 漸化式、ベルマン-フォード = ダイクストラ、ビタビ = 総当たり、log-sum-exp の誤差 ≤ h·ln 2、距離変換 = 総当たりなどを照合しています。トロピカル曲線や多項式の形（幾何）はシリーズ 38、PERT はシリーズ 30、モルフォロジーはシリーズ 19、ルジャンドル変換はシリーズ 43 で扱っています。
