# シリーズ61：クラスタリング ─ p5.js コード集

答え（ラベル）なしで「似たもの同士」をまとめる ― クラスタリングを**自分の手で計算して**確かめるワークショップ（110分）のコード集です。距離のいろいろと最小化としての k-means（k-means++ とやり直し）、k の選び方（エルボー法とシルエット係数）、k-means が苦手な形から始めて、凝集型クラスタリングの 4 つの連結法とデンドログラム、DBSCAN・平均値シフト・混合ガウス分布と EM・スペクトラルクラスタリング、正解との一致の測り方（ARI・NMI）、次元の呪い、自己組織化マップ、画像の減色、音とカメラまで、どれも機械学習のライブラリを使わずに**本当に計算した**シミュレーションです。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series61/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「クラスタリングの道具」（合成データ、k-means と k-means++、シルエット係数、ランス-ウィリアムズの凝集型クラスタリング、DBSCAN、混合ガウス分布の EM、ヤコビ法、ARI・NMI、自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. データはどれも種つきの乱数で作った合成データ（かたまり・三日月・同心円・細長い・密度や大きさがちがう・外れ値）。クリックで点を足せるスケッチもあります

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `kmeansBest is not defined` / `agglomerate is not defined` | 一番下の「クラスタリングの道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 画面右下の「自己テスト」が ✗ になる | 道具の中の式を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 動きが重い・止まる | 点を足しすぎた（09 はヤコビ法で n³ に比例）。R でデータを作り直す。NPTS を小さく |
| 毎回ちがう答えになる・ならない | 乱数は種つき。R（新しいデータ）や I（初期値）で種を変えると答えが変わる。k-means は初期値しだい |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

距離関数、ロイドのアルゴリズムと k-means++（種つき）、シルエット係数（ちょうど O(n²)）、エルボー法、ランス-ウィリアムズの更新式による凝集型クラスタリング（単連結・完全連結・群平均・ウォード法）とデンドログラム、コーフェン相関係数、マス目で近くを探す DBSCAN、ガウス核の平均値シフト、共分散つき混合ガウス分布の EM（log-sum-exp と共分散の下限）と BIC、スペクトラルクラスタリング（ガウスの近さ、正規化ラプラシアン、ヤコビ法の固有ベクトル）、分割表からの ARI と NMI、自己組織化マップ、べき乗法の PCA まで、すべてゼロから実装しています。各スケッチは起動時に自己テストで、距離の公理（コサイン距離は三角不等式が破れる）、J が増えないこと、k-means++ の平均が良いこと、シルエットが本当の k で最大、ランス-ウィリアムズ = 総当たりの再計算、合体の高さの単調性と最小全域木、コーフェン距離が超距離、DBSCAN = 全部の組を調べた実装、平均値シフトの動き = h²∇f/f、EM の対数尤度が減らないこと、三日月でスペクトラル ARI ≥ 0.95・k-means < 0.6、ARI = 2 点の組の数え上げ、次元とともに最遠 ÷ 最近 → 1、SOM の量子化誤差が減ること、k とともに PSNR が上がることなどを照合しています。基本の k-means はシリーズ 17 の 10、単連結の木（H0 のパーシステンス）はシリーズ 9 の 13、ファジィ c-平均法はシリーズ 50 の 11、ボロノイ図はシリーズ 22、ネットワークのコミュニティはシリーズ 8 の 09、PCA はシリーズ 60 で扱っています。
