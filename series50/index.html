ファジィ理論
コード集

「だいたい」「かなり」「やや暑い」を、数で計算する。メンバーシップ関数と演算、言語変数とヘッジ、ファジィ関係と拡張原理から、マムダニ型・高木-菅野型の推論と非ファジィ化まで、所属度・規則の強さ・重心を本当に計算して見せます。倒立振子と車庫入れのファジィ制御、ファジィクラスタリング、画像、意思決定、音とカメラまで。

p5.js Web Editor を開く → ZIP でダウンロード
01番号を開いて「コードをコピー」
02エディタの sketch.js を全部消して貼り付け
03左上の ▶ で実行
04どれも一番下の「ファジィの道具」まで全部コピー。音（14）はまずクリック
