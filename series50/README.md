# シリーズ50：ファジィ理論 ─ p5.js コード集

「背が高い」「やや暑い」「かなり近い」― はっきり線を引けない言葉を、0 か 1 ではなく 0〜1 の「所属度」で扱うのがファジィ理論です。メンバーシップ関数と演算、言語変数とヘッジ、ファジィ関係と拡張原理から、マムダニ型・高木-菅野型の推論と非ファジィ化まで、所属度・規則の強さ・集約した形・重心を本当に計算して見せるワークショップ（110分）のコード集です。倒立振子と車庫入れのファジィ制御、ファジィクラスタリング、画像、意思決定、音とカメラまで。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series50/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「ファジィの道具」（メンバーシップ関数・推論・非ファジィ化）があるので、**一番下まで全部コピー**する。🔊 音を使うスケッチ（14）は、実行したらまずキャンバスを1回クリック。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `mamdani is not defined` / `trimf is not defined` | 一番下の「ファジィの道具」までコピーできていない → 全部コピーし直す |
| 画面左下の「自己テスト」が ✗ になる | 道具の中の式や規則の表を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 06・09 で出力が「発火なし → まん中」になる | どの規則も強さ 0。入力が範囲の外か、規則の表を消しすぎた |
| 09 で棒が倒れる | 規則の表を変えすぎた → D で表をもとに戻す。R でやり直し |
| 10 で車庫に入らない | 車庫に近すぎる所から出発した。上のほう（y が大きい所）をクリック |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |

所属度・規則の強さ・集約した形・重心（折れ線の区間ごとに正確に積分）は、すべて画面の数字のとおりに計算しています。各スケッチは起動時に自己テストで、手で計算できる値（三角 (2,3,4) + (4,5,6) = (6,8,10)、max min(μ, 1 − μ) = 0.5、切った三角の重心、max-min 合成の行列、FCM の所属度の和 = 1 と J が増えないこと、高木-菅野の重み付き平均、倒立振子が 10° から立つこと など）と照合しています。制御のスケッチ（09・10）は運動方程式を 4 次のルンゲ＝クッタ法で解いています。
