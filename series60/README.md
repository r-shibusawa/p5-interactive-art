# シリーズ60：主成分分析 ─ p5.js コード集

たくさんの数をもつデータを「いちばんばらつく向き」から見る ― 主成分分析（PCA）を**計算の道具として**使うワークショップ（110分）のコード集です。平均・分散・共分散から始めて、射影した分散が最大の向き、共分散行列と固有ベクトル、3 次元の点群（ヤコビ法）、べき乗法とデフレーション、特異値分解、寄与率とスクリープロット、復元と誤差、固有顔、自分で描いた文字の主成分、標準化と白色化、カーネル PCA、独立成分分析（FastICA）、外れ値、音色マップ、カメラ映像の色まで、どれも機械学習のライブラリを使わずに**本当に計算した**シミュレーションです。データはすべて種つきの乱数で作った合成データ（実在のデータセットではありません）。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series60/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「主成分分析の道具」（共分散行列、ヤコビ法、部分空間反復法、白色化、カーネル、FastICA、自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. 約束：データ X は「n 行 × d 列」（1 行 = 1 個のデータ）。共分散は n − 1 で割る（C = Xcᵀ Xc / (n − 1)）。復元誤差も同じく Σ‖x − x_hat‖² / (n − 1) で、これが捨てた固有値の和になります

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `jacobiEigen is not defined` / `covMatrix is not defined` | 一番下の「主成分分析の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 画面右下の「自己テスト」が ✗ になる | 道具の中の式を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 主成分の矢印が急に反対を向く | 固有ベクトルは向き（符号）が決まらない。v も −v も同じ主成分（いちばん大きい成分を正にそろえている） |
| 起動に少し時間がかかる | 08（顔 200 枚）と 11（200×200 のグラム行列）は最初に計算するため。毎フレームは計算し直さない |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

平均と中心化、共分散行列（n − 1 で割る）、対称行列の固有値分解（ヤコビ法、d ≤ 64）、べき乗法とデフレーション、部分空間反復法とグラム行列による高次元の主成分（08・09）、XᵀX の固有値分解による特異値分解、射影と復元、寄与率、標準化、白色化、RBF カーネルと特徴空間での中心化、FastICA（tanh、対称な直交化）、中央値と重みつき共分散による外れ値対策は、すべてゼロから実装しています。データは種つき乱数（mulberry32）で作った合成データです。各スケッチは起動時に自己テストで、共分散行列の対称性と半正定値性、解の公式の固有対 C v = λ v、3600 本の向きの総当たりの最大 = 第 1 固有ベクトル（0.1° 以内）、ヤコビ法の正規直交性と C V = V Λ、固有値の和 = トレース、べき乗法 → ヤコビ法の固有ベクトル、U Σ Vᵀ = X と σ²/(n − 1) = λ、隠れた次元の回復、復元誤差 = 捨てた固有値の和、白色化した共分散 = I、カーネル PCA が同心円を分ける（95% 以上）のにふつうの PCA は分けない、FastICA が元の信号を |相関| ≥ 0.98 で取り出す、外れ値で PC1 が回り反復重みづけでは回らないことなどを照合しています。最小 2 乗の回帰はシリーズ 17 の 15、勾配法による最適化はシリーズ 49 で扱っています（このシリーズのべき乗法は固有値の計算法です）。
