# シリーズ47：結び目理論 ─ p5.js コード集

ひもの両端をつないだ輪は、どこまでほどけるのか。結び目と絡み目の図を描き、ライデマイスター移動で変形し、交点の数・ねじれ数・絡み数・彩色・アレクサンダー多項式・ジョーンズ多項式といった「不変量」を図のデータから本当に計算して見分けるワークショップ（110分）のコード集です。組みひも・トーラス結び目・連結和・結び目表、ザイフェルト曲面と DNA、音とブラシまで。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series47/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「結び目の道具」（不変量の計算）があるので、**一番下まで全部コピー**する。🔊 音を使うスケッチ（14）は、実行したらまずキャンバスを1回クリック。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `KNOTS is not defined` / `diagramOf is not defined` | 一番下の「結び目の道具」までコピーできていない → 全部コピーし直す |
| 画面左下の「自己テスト」が ✗ になる | 道具の中の表（KNOTS の PD 符号）や計算を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 不変量が「省略」になる | 交点が多すぎる（ジョーンズは 2^n 通りの計算）。`BRACKET_MAX` を上げると計算するが重くなる |
| 03 で輪がなかなか丸くならない | N で別のごちゃごちゃに。F（ふくらませる力）が ON か確認、↑ で速く |
| 01・15 で交点が見つからない | 線を交差させて描く。短すぎる線は消える |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくても無地で動く） |

不変量はすべて、図のデータ（PD 符号：交点ごとに 4 本の辺の番号）から計算しています。表の値は Knot Atlas / KnotTheory の約束（A = t^(−1/4)）と同じで、右手系三葉結び目は V = t + t³ − t⁴、左手系は −t⁻⁴ + t⁻³ + t⁻¹ です。各スケッチの自己テストで、知られている値（自明な結び目 V = 1、8 の字 V = t⁻² − t⁻¹ + 1 − t + t²、行列式 1・3・5・5・7、三葉の 3 彩色 9 通り など）と照合しています。
