# シリーズ35：カタストロフィー理論 ─ p5.js コード集

原因はなめらかに変わるのに、結果が突然とぶ。ルネ・トムのカタストロフィー理論を、転がるボール・折りたたまれた曲面・ゴムひもの機械・光の網目・船の転覆・草原の崩壊で体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series35/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（13・14）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| ボールがとばない | コントロールが分岐集合（赤い線・黄の線）をこえていない。範囲を広げるか、a を負に（谷を 2 つに） |
| 動きがガタガタ・数値が暴れる | 刻み（`dt` や `0.004`）が大きすぎる。半分にして、かわりにループの回数を 2 倍に |
| 画面が固まる | 色分けの細かさを減らす（06・07 の `field` の大きさ、09 の `nRays`） |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

式はトム『構造安定性と形態形成』、ジーマン『Catastrophe Theory: Selected Papers』、ポストン & スチュワート『Catastrophe Theory and its Applications』と同じ形にしてあります。12 はメイ（1977）の放牧モデル、早期警報はシェファーらの研究にもとづいています。
