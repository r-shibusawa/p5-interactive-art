# シリーズ63：強化学習 ─ p5.js コード集

正解を教えてもらわずに、**報酬だけを手がかりに試行錯誤で行動を学ぶ** ― 強化学習のワークショップ（110分）のコード集です。スロットマシンの「探索と活用」から始めて、マルコフ決定過程とグリッドワールド、価値反復・方策反復、モンテカルロと TD 学習、Q 学習と SARSA（崖歩き）、探索の工夫、タイルコーディングで山登り車、モデルを使う Dyna-Q、方策勾配 REINFORCE、小さなニューラルネットの Q 学習（経験再生とターゲットネットワーク）、三目並べの自己対戦、報酬の設計と「ずる」、そして人が耳や体で報酬を与える学習まで、どれも**機械学習のライブラリを使わずにゼロから計算した**シミュレーションです。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「強化学習の道具」（種つきの乱数、グリッドワールド、グラフ、自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. 学習は 1 フレームに数ミリ秒ずつ進めるので、画面は止まりません。**F キーで速さ**を変えられます（速いときは 1 フレームに何百エピソードも）
6. 記号：状態 s、行動 a、報酬 r、割引率 γ、価値 V(s)、行動価値 Q(s, a)、方策 π、学習率 α、探索の割合 ε

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `seedRng is not defined` / `buildMdp is not defined` | 一番下の「強化学習の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 画面右下の「自己テスト」が ✗ になる | 道具やアルゴリズムの式を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 学習がなかなか進まない | F キーで「速い」に。それでも進まないときは ε や α が 0 になっていないか確かめる |
| 画面がカクカクする | 1 フレームの計算時間（`performance.now() - t0 < 6` の 6 ミリ秒）を小さくする |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもクリックで動く） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

乱数はすべて種つき（mulberry32）なので、同じ種なら毎回同じ結果になります。ε-greedy・UCB1・トンプソン抽出（ベータ分布）、マルコフ決定過程（すべりやすさつき）、価値反復・方策反復（収束の判定つき）、初回訪問モンテカルロと TD(0)、Q 学習と SARSA、タイルコーディング + SARSA、Dyna-Q / Dyna-Q+、REINFORCE（ベースラインつき）、隠れ層 1 層のニューラルネット（手書きの誤差逆伝播と Adam、経験再生、ターゲットネットワーク）、アフターステートの TD 学習、ポテンシャルに基づく報酬整形、勾配バンディットはすべてゼロから実装しています。学習は 1 フレームに数ミリ秒ずつ進め、画面は 60fps のままです。各スケッチは起動時に自己テストで、遷移確率の合計 = 1、価値反復の収束とベルマン最適方程式、方策反復 = 価値反復の最適方策、ランダムウォークの推定 → 1/6〜5/6、Q 学習の道 = 最短の道、崖歩きでの SARSA と Q 学習の差、山登り車が 200 歩未満でゴール、Dyna-Q の計画の効果、REINFORCE の勾配の平均 = 本当の勾配、誤差逆伝播 = 数値微分、三目並べででたらめな相手に負けない、ポテンシャル整形で最適方策が変わらないことなどを照合しています。人が設計した制御で棒や台車を動かす話はシリーズ 20（制御工学）とシリーズ 50、勾配法はシリーズ 49、ゲーム理論はシリーズ 30 で扱っています。
