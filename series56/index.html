束論
コード集

「順序」から生まれる代数。半順序とハッセ図、約数と部分集合の束、上限と下限から、分配束・モジュラー束・ブール代数と論理回路の簡単化、ガロア接続と形式概念分析、束の不動点定理とプログラム解析、鎖と反鎖・ディルワースの定理・メビウス関数まで。どの束も本当に計算した有限の構造で、起動時の自己テストで答えを確かめています。

p5.js Web Editor を開く → ZIP でダウンロード
01番号を開いて「コードをコピー」
02エディタの sketch.js を全部消して貼り付け
03左上の ▶ で実行
