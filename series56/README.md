# シリーズ56：束論 ─ p5.js コード集

「順序」から生まれる代数 ― 半順序・上限と下限・束を、**本当に計算した有限の構造**で確かめるワークショップ（110分）のコード集です。矢印からハッセ図を作り、約数の束と部分集合の束で上限 = 最小公倍数・和集合を確かめ、分配束とモジュラー束（N5 と M3）、補元とブール代数、論理式の簡単化（クワイン-マクラスキー法）、ガロア接続と閉包、形式概念分析、束の不動点定理とプログラム解析、鎖と反鎖・ディルワースの定理・メビウス関数まで進みます。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series56/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「束論の道具」（順序の表・閉包・被覆・上限と下限・ハッセ図・自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. 順序は n × n の 0/1 の表 R[i][j]（1 = 「i ≤ j」）で持っています。ハッセ図の辺 = 被覆（間にはさまる元がない組）、高さ = ランク（下からの最長の鎖の長さ）

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `makePoset is not defined` / `drawHasse is not defined` | 一番下の「束論の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 画面右下の「自己テスト」が ✗ になる | 道具の中の式を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 00 でハッセ図が出ない | 矢印が輪になっている（反対称律 ✗）。D で最後の矢印を消す |
| 06 で式が赤い字になる | 式がまだ途中（かっこが閉じていない・演算子が続いている）。Backspace で直す。前の正しい式で表示は続く |
| 動きが重い | 12 の k = 5 や 360 の約数は要素が多い。← → で小さい例にもどす |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

どの束も、順序の 0/1 の表から推移的閉包（ワーシャル法）、被覆（推移的簡約）、ランク（下からの最長の鎖）を計算し、上限・下限は「上界の中の最小元」として表から求めています（一意であることも確かめています）。分配律・モジュラー律はすべての 3 つ組で、N5・M3 は部分束（∨ と ∧ で閉じた部分）としてさがします。概念束は導出作用素で属性の部分集合を全部調べ、不動点はクリーネの反復、最小の鎖の分割は二部グラフの最大マッチング、メビウス関数は区間ごとの再帰です。各スケッチは起動時に自己テストで、60 の約数の束が 12 個で上限・下限 = lcm・gcd、部分集合の束の辺が 32 本、輪になる関係を半順序でないと判定、N5 はモジュラーでなく M3 は分配でない、ブール代数の大きさが 2 のべき、簡単にした論理式が 16 行すべてで等しく主項が総当たりの結果と一致、g∘f が拡大・単調・冪等、i ≠ j の 4 × 4 の文脈の概念が 16 個、クリーネの反復の答えがどの不動点よりも下、データフローの答えが道の探索と一致、最大反鎖 = 最小の鎖の数（全部の部分集合と照合）、スペルナー数 6、μ(1, n) = 数論の μ(n)（n ≤ 100）と反転公式などを照合しています。
