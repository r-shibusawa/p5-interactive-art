# シリーズ26：オリガミクス ─ p5.js コード集

1 枚の紙を「折る」ことを数学として動かす。折り紙の公理、定規とコンパスではできない作図（角の三等分・∛2）、芳賀の定理、平らにたたむ条件（前川・川崎の定理）、ミウラ折りや吉村パターンの工学、ドラゴン曲線までを体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series26/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（13・14）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 折り線が出ない・「紙の中で折れない」 | 点が離れすぎ・近すぎ。02 は `a` を小さく、01 の O5〜O7 は点や直線を動かして解がある配置に |
| 3D のスケッチが真っ暗・見えない | ドラッグで視点が裏側に回っている → ▶ で実行し直す。ホイールで近づきすぎていないか確認 |
| 08 が「これ以上折れない」で止まる | 川崎の条件を満たさない頂点（3）は途中までしか折れない。← で戻すか 1・2 に切りかえ |
| 画面が重い | 12 の n、13 の n を小さく。11 は n が 7 を超えると断面を描かない |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなければ模様の紙になる） |

折り紙の公理は藤田文章・羽鳥公士郎、芳賀の定理は芳賀和夫『オリガミクス』、平坦折りの条件は前川淳・川崎敏和、ミウラ折りは三浦公亮による。教科書としては Demaine & O'Rourke『Geometric Folding Algorithms』、Lang『Origami Design Secrets』も参考にしてください。
