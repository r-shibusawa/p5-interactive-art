# シリーズ57：四元数と八元数 ─ p5.js コード集

「3 次元の回転を、掛け算 1 回で書けないか？」― 複素数の先にある「数」、四元数と八元数を**自分で計算して**確かめるワークショップ（110分）のコード集です。複素数と平面の回転から、ハミルトンの i² = j² = k² = ijk = −1・交換しない掛け算・ノルムと逆元（複素数から四元数へ）、回転を表す q v q*・オイラー角とジンバルロック・slerp・ベルトのトリック（四元数と回転）、アークボール・角速度の積分・4 次元の回転とホップの円・四元数のジュリア集合（四元数を使う）、ケーリー-ディクソン構成・ファノ平面の八元数・十六元数の零因子（八元数とその先）まで。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「四元数の道具」（四元数の積・共役・回転・slerp、ケーリー-ディクソンの積、3D の描画、自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. 四元数は配列 `[w, x, y, z]` = w + xi + yj + zk。3D の向きは x 右・y 上・z 手前（右手系）。回転はすべて q v q* で計算して頂点を置いている

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `qMul is not defined` / `hudMake is not defined` | 一番下の「四元数の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 画面右下の「自己テスト」が ✗ になる | 道具の中の式を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 物体がふくらむ・ゆがむ | 08 の「2：近似の更新」はわざとそうなる。1 を押すか R でやり直す。四元数なら N（正規化）を ON に |
| 11 の絵がなかなか出ない | 少しずつ描いている（黄色の線が進む）。Q で画素を減らすと速い |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

四元数の積（ハミルトン積）・共役・ノルム・逆元・exp/log・slerp、八元数と十六元数の積（ケーリー-ディクソン構成 (a, b)(c, d) = (ac − d*b, da + bc*)）は、どれも p5.js の関数を使わずに一から書いています。ファノ平面の表（13）は、この積の約束から 7 本の向き付きの線を求め直して一致を確かめています。3D の回転は p5 の rotate を使わず、全部の頂点を q v q* で回して置いています。各スケッチは起動時に自己テストで、i² = j² = k² = ijk = −1 と ij = −ji = k、ランダムな p, q で |pq| = |p||q|（1e-9）、q q⁻¹ = 1、q v q* = 回転行列の結果と長さの保存、q と −q が同じ回転、回転の合成 = 四元数の積、slerp の両はしと一定の角速度、ピッチ 90° でヤコビアンの階数 2、RK4 で積分した q が単位のままで一定の ω の厳密解 exp(½ωt) と一致、p x q が 4 次元の長さを保つ、ファノ平面の表 = ケーリー-ディクソンの積、八元数で |ab| = |a||b| と交代性 (aa)b = a(ab) と非結合の例、十六元数の零因子 (e1 + e10)(e4 − e15) = 0、整数でのオイラーの 4 平方恒等式などを照合しています。
