# シリーズ27：トポロジー ─ p5.js コード集

伸ばしても曲げても変わらない「つながり方」を見る、ゴムの幾何学。一筆書きとオイラー標数、メビウスの帯とクラインの壺、曲面の分類、結び目、ループと回転数、毛玉の定理までを、形をさわって確かめるワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series27/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（13・14）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 3D の形が見えない・真っ黒 | `createCanvas(windowWidth, windowHeight, WEBGL)` の `WEBGL` を消していないか確認。ドラッグで視点を戻す |
| 線が引けない（02） | 交わる線は引けない（平面グラフ）。点から点へドラッグする |
| 画面が重い | 点・毛・解像度を減らす（04 の `nu`、12 の `nHair`、15 の `OW`・`OH`） |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（カメラがなければ 15 は模様で動く） |

位相的データ解析（バーコードなど）はシリーズ 9 で扱っています。不動点定理はシリーズ 31 でくわしく扱います。
