# シリーズ34：暗号理論 ─ p5.js コード集

秘密を守る数学を、自分の手で破って・つくって体験する。シーザー暗号の総当たりと頻度分析から、ワンタイムパッド、ブロック暗号と利用モード、ハッシュ、ディフィー＝ヘルマン、RSA、楕円曲線、デジタル署名、ゼロ知識証明、秘密分散まで、古典から現代の暗号までを小さな数で動かすワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

> ⚠️ すべて**教育用**です。鍵や素数をわざと小さくしてあるので、実際の安全な暗号には使わないでください。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series34/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（14）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する
5. 文字を打つスケッチ（00・02・04・07・11）は、先にキャンバスを1回クリックしてからキーを押す

## 困ったときは

| 症状 | 解決法 |
|---|---|
| キーを押しても文字が入らない | キャンバスを1回クリックしてから打つ（エディタのコード欄に入力されている） |
| 解読・推測が外れる | 文が短すぎる。00・01・02 の平文（`PLAIN`）を長くすると頻度分析が当たりやすい |
| 画面が固まる | 08 のイブの速さ（←→）を下げる、07 の `kBits` を小さく、15 の `VW`・`VH` を元に戻す |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可。カメラがなくても 15 は動く絵で動く |

すべて教育用の小さなモデルです。考え方は本物（AES・SHA-256・RSA・ECDH・シャミア）と同じですが、鍵が小さいのですぐ破れます。もっと知りたい人は、サイモン・シン『暗号解読』、結城浩『暗号技術入門』へ。
