# シリーズ36：光学 ─ p5.js コード集

光はまっすぐ進み、鏡ではね返り、ガラスで折れ曲がり、波として重なり合って縞や色をつくる。反射・屈折・レンズの結像から、干渉・回折・偏光、虹・色・カメラまで、光学を 2D の光線追跡とピクセル計算で体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series36/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（13）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 光線が出ない・消える | 光源が鏡や円の中に入っている。マウスを外へ。`maxBounce` を増やしすぎていないか確認 |
| 屈折光が描かれない | 全反射している（HUD に「全反射！」）。入射角を小さくするか n を入れ替える |
| 画面がカクカクする | 06・08・15 の `cell` を 4 → 6 に、05 の `rayCount` を減らす、11 の `histN` を減らす |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| `wavelengthToRGB is not defined` | 一番下の「色の道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

すべて 2D の簡易シミュレーションです。式は光学の教科書（Hecht『Optics』、Pedrotti『Introduction to Optics』など）と同じ形にしてあります。
