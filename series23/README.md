# シリーズ23：群と対称性 ─ p5.js コード集

「動かしても変わらない」= 対称性。その対称性どうしの掛け算のルールが「群」です。正多角形の回転と裏返し、置換、15 パズル、壁紙模様、ネックレスの数え上げ、そしてルービックキューブまで、群論の考え方を自分の手で動かして体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series23/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（14）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する。ルービックキューブ（10〜13）も一番下の「キューブの道具」まで全部コピーする

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `newCube is not defined` / `FACE is not defined` | 一番下の「キューブの道具」までコピーできていない → 全部コピーし直す |
| キーを押してもキューブが回らない | キャンバスを1回クリックしてから押す。Caps Lock が ON だと全部逆回り（'）になる |
| 11 の自動くり返しが終わらない | 位数が大きい（6 は 1260 回）。↑ で速くするか、スペースで 1 回ずつ |
| 07 が一瞬止まる | n = 8・k = 4 は 65,536 通りを全部調べている。n か k を小さく |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（カメラがなくても 15 は自動の模様で動く） |

キューブの回転は 90° の整数回転だけで計算しているので、何千回回しても誤差がたまりません。式や数は群論の入門書（『群論の味わい』、Armstrong『Groups and Symmetry』、Joyner『Adventures in Group Theory』など）と同じ形にしてあります。
