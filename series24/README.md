# シリーズ24：力学 ─ p5.js コード集

F = ma から始めて、運動量・エネルギー・角運動量の保存則、振動と波、惑星の運動、剛体の回転、最小作用の原理まで。古典力学の「法則」を、自分で動かせるシミュレーションで確かめるワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series24/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（13・14）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 物体が飛んでいく・数字が NaN になる | 時間の刻み `dt`（または `h`）が大きすぎる。半分にするか、分割の回数（`sub`）を増やす |
| エネルギーがだんだん増える | オイラー法のせい（01）。半陰的オイラー法・ベルレ法・RK4 に変える |
| 画面が固まる・重い | 円盤・点の数を減らす（04 の `N`、14 の `MAXP`）。分割の回数 `sub` を減らす |
| 3D（11・12）が真っ黒・動かない | `createCanvas(…, WEBGL)` のままか確認。ドラッグで見る向きを変えてみる |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない | キャンバスを1回クリック。端末の音量・消音スイッチも確認 |

すべて簡易シミュレーションですが、式は力学の教科書（ファインマン物理学、ランダウ＝リフシッツ『力学』、ゴールドスタイン『古典力学』など）と同じ形にしてあります。カオス（二重振り子・ローレンツ）はシリーズ 4、制御（倒立振子）はシリーズ 20 も見てください。
