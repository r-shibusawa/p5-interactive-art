# シリーズ14：グラフアルゴリズム ─ p5.js コード集

参考：Cormen ほか『Introduction to Algorithms』

グラフアルゴリズムを、1 手ずつ動くアニメーションで体験するワークショップ（110分）のコード集です。
幅優先探索・深さ優先探索とその応用、最小全域木、単一始点・全点対の最短経路を、日本語で書いた疑似コードと並べて動かします。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series14/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「グラフを描く・動かすための道具」があります。**一番下まで全部コピー**してください
5. 共通の操作：**スペース＝再生/停止、→＝1 手ずつ、↑↓＝速さ、R＝最初から、S＝画像を保存**。右側の疑似コードで、いま実行している行が光ります

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `drawEdge is not defined` など | 一番下の「グラフを描く・動かすための道具」までコピーできていない → 全部コピーし直す |
| スペースを押しても動かない | 点が 1 つもない（C で消した）→ 1〜4 でお手本を読み込む。終わったら R で最初から |
| 速すぎて追えない | → キーで 1 手ずつ。↓ で遅く |
| 最短経路が ∞ のまま | 始点からその点への道がない（矢印の向きも確認） |
| 音が出ない（13） | キャンバスを1回クリックしてからスペース |
