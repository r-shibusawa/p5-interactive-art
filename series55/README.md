# シリーズ55：熱力学 ─ p5.js コード集

「温度って何？」「熱はなぜ熱い所から冷たい所へしか流れない？」― 熱・温度・エントロピーを、**分子のふるまいから**確かめるワークショップ（110分）のコード集です。箱の中の分子の衝突から温度と圧力を測り、熱伝導・相変化、PV 図の 4 つの過程とカルノーサイクル・ヒートポンプ、混合と不可逆性、アインシュタイン固体の場合の数、ボルツマン分布、マクスウェルの悪魔、イジング模型の相転移、ファン・デル・ワールス気体、ブラウン運動まで、どれも**本当に計算した**シミュレーションです。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series55/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「熱力学の道具」（乱数・剛体円板の気体・グラフ・自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. 分子のスケッチは換算単位（ボルツマン定数 k = 1、分子の質量 m = 1）。2 次元なので「体積」は面積 A、温度は ⟨½mv²⟩ = kT

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `makeGas is not defined` / `plotAxes is not defined` | 一番下の「熱力学の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 画面右下の「自己テスト」が ✗ になる | 道具の中の式を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 分子がすりぬける・動きがおかしい | RAD を小さくしすぎた、または速さを上げすぎた。R でやり直す |
| 熱伝導の色がしま模様になって爆発する | R_MAX（02）や R_DIFF（15）を 1/4 より大きくした。0.24 以下にもどす |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

分子は剛体円板（弾性衝突、セルリストで近いペアだけ調べる）または、やわらかい円板を速度ベルレ法で解いたもの（07）で、温度 = 平均運動エネルギー、圧力 = 壁が受けた力積 ÷（壁の長さ × 時間）として測っています。熱伝導は陽解法の差分（安定条件 r ≤ 1/4）、PV 図の仕事は細かく分けた台形の数値積分、アインシュタイン固体の場合の数は BigInt で正確に、イジング模型は種つき乱数のメトロポリス法、ファン・デル・ワールスの共存は二分法で求めています。各スケッチは起動時に自己テストで、衝突でエネルギーと運動量が保存されること、測った PA/(NkT) が 1 + 2η に近いこと、断熱でゆっくり圧縮すると T·A が一定（2 次元、γ = 2）、断熱の箱で熱の合計が一定、等温の W = nRT ln(V₂/V₁)、カルノーの効率 = 1 − Tc/Th、Ω(3, 3) = 10 とヴァンデルモンドの等式、ボルツマン分布の傾き、T → 0 のイジング模型が基底状態のまま、オンサーガーの Tc = 2/ln(1 + √2)、T = 0.9 の共存圧力 0.647、ランダムウォークの MSD = 2dDt などを照合しています。値は換算単位なので、本物の気体の数値とは単位がちがいます（形と関係を見るためのシミュレーションです）。
