# シリーズ46：群知能 ─ p5.js コード集

1 匹 1 匹は単純なルールで、となりとやりとりするだけ。それなのに群れ全体は渦を巻き、リズムをそろえ、最短路や良い答えを見つけ、巣の場所まで決める。群れの動き・群れによる最適化（ACO・PSO・人工蜂・ホタル）・スティグマジー（環境を介した協調）・集団の意思決定を、本物のアルゴリズムを動かして体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series46/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（14）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 群れがバラバラ・すぐ散る（00・03） | 00 はスペースで捕食者を休ませる。03 は `1〜4` のプリセットを押してから `R` |
| 最適化が途中で止まる（04〜07） | 局所解。`R` でやり直すか、05 は w を上げる、06 は limit を下げる、07 は α を上げる |
| 都市を全部消したら止まった（04） | 都市が 3 つ以上になるまでクリックで置く。`1` か `2` で元に戻る |
| 画面が重い・カクカクする | 01 の粒子（↓）、08 の速さ（←）、09 の速さ（↓）、15 の群れの数（↓）を減らす |
| `startAudio is not defined`・`drawPlot is not defined` | 一番下の「道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラなしでもマウスで動く） |

すべて 2D の簡易モデルです。式は群知能の教科書・原論文（Reynolds 1987、Vicsek ほか 1995、Mirollo & Strogatz 1990、Couzin ほか 2002、Dorigo & Stützle『Ant Colony Optimization』、Kennedy & Eberhart 1995、Karaboga 2005、Yang 2008、Deneubourg ほか 1990・1991、Helbing ほか 1997、Seeley『Honeybee Democracy』など）と同じ形にしてあります。
