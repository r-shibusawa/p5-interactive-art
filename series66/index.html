オートマトン
コード集

状態と遷移だけでできた「計算する機械」。自動販売機と信号機の状態機械、DFA の設計、NFA と部分集合構成、最小化、正規表現から NFA へ、積の構成と言語の演算、ポンピング補題ゲーム、字句解析器、プッシュダウンオートマトンとかっこ、文脈自由文法と CYK 構文解析、チューリング機械と忙しいビーバー、ゲームの敵キャラの状態機械、エイホ-コラシック法、音とカメラまで。どのスケッチもライブラリなしで本当に計算し、起動時の自己テストで答えを確かめています。

p5.js Web Editor を開く → ZIP でダウンロード
01番号を開いて「コードをコピー」
02エディタの sketch.js を全部消して貼り付け
03左上の ▶ で実行
04どれも一番下の「オートマトンの道具」まで全部コピー。07・13 は Tab で編集モード（04 は Tab で入力欄の切りかえ）。音（14）はまずクリック、音量は小さめから
