# シリーズ16：行列・線形計画・FFT・数論 ─ p5.js コード集

「行列演算」「線形計画法」「多項式と FFT」「整数論的アルゴリズム」を、動かして見るワークショップ（110分）のコード集です。

参考：Cormen ほか『Introduction to Algorithms』

LUP 分解・シンプレックス法・FFT のバタフライ・ユークリッドの互除法・RSA 暗号・ミラー–ラビン法などを、1 ステップずつ止めながら観察できます。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series16/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. ほとんどのスケッチは **スペースで 1 ステップ、A で自動再生、R でやり直し**。🔊 のスケッチは一番下の「道具」まで全部コピーして、まずキャンバスをクリック

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 「特異行列」と出る | 行（列）が他の行の組み合わせになっている → 逆行列も一意の解もない。数を少し変える |
| LP が「非有界」「実行不能」 | 制約の向き（F）や位置を見直す。原点が領域の外でも 04 は補助 LP で対応 |
| 09 の答えが BigInt と一致しない | けた数が多すぎて浮動小数点の誤差が出た → けた数を減らす |
| 13 で「M ≥ n」 | 文字コードが n より大きい → 鍵 2（日本語 OK）に切りかえる |
| `startAudio is not defined` | 一番下の「音の道具」までコピーできていない → 全部コピーし直す |
| 音が出ない | キャンバスを1回クリック ／ ブラウザの音量を確認 |

コードは教育用の簡易実装です（小さな数・小さな行列が目安）。
