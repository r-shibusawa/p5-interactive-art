# シリーズ65：マルコフ連鎖 ─ p5.js コード集

**「次にどうなるかは、今の状態だけで決まる」** 確率の動き ― マルコフ連鎖のワークショップ（110分）のコード集です。天気の連鎖と遷移行列から始めて、n ステップ後の分布、定常分布、状態の分類、ギャンブラーの破産、すごろくの平均手数（基本行列）、グラフ上のランダムウォーク、トランプを何回切ればよいか、文字の n-gram による文章生成、隠れマルコフモデル、連続時間マルコフ連鎖、メトロポリス-ヘイスティングス法とギブスサンプリング、エーレンフェストの壺、そして自分の演奏やカメラ映像から学ぶ連鎖まで、どれも**行列の計算とシミュレーションをゼロから実装して、答えが一致することを確かめる**スケッチです。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series65/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「マルコフ連鎖の道具」（行列の計算、定常分布、状態の分類、遷移図やグラフを描く道具、種つきの乱数、自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. 長いシミュレーションは 1 フレームに数ミリ秒ずつ進めるので、画面は止まりません
6. 記号：遷移行列 P（`transP[i][j]` = i の次に j へ行く確率、各行の合計 = 1）、分布 μ（横ベクトル）、定常分布 π（π P = π）、基本行列 N = (I − Q)⁻¹、生成行列 Q（連続時間、各行の合計 = 0）

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `stationaryExact is not defined` / `seedRng is not defined` | 一番下の「マルコフ連鎖の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 画面右下の「自己テスト」が ✗ になる | 道具や式を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 確率が NaN や ∞ になる | 遷移行列の行の合計が 1 か確かめる。ゴールに行けないすごろく（05）は平均手数が ∞ と表示される |
| 画面がカクカクする | 1 フレームの計算時間（`performance.now() - t0 < 6` の 6 ミリ秒）や 1 フレームの歩数を小さくする |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

乱数はすべて種つき（mulberry32）なので、同じ種なら毎回同じ結果になります。遷移行列の積と P^n、ガウスの消去法による定常分布と逆行列、べき乗法、タージャンの強連結成分と周期（gcd）、吸収マルコフ連鎖の基本行列、GSR リフルシャッフルの上昇列の式（オイラー数）、文字の n-gram とエントロピー率、スケーリングつきの前向き・後ろ向きアルゴリズム、生成行列と一様化（行列の指数関数との比較）、メトロポリス-ヘイスティングス法（採択率・自己相関・有効サンプル数）、ギブスサンプリング、エーレンフェストの壺とカックの公式は、すべてゼロから実装しています。各スケッチは起動時の自己テストで、行の合計 = 1（生成行列は 0）、P^(m+n) = P^m P^n、連立方程式の π = べき乗法 = 長いシミュレーション、周期と既約性の総当たりとの一致、破産の公式 = 基本行列 = シミュレーション、すごろくの基本行列 = 価値反復 = シミュレーション、π ∝ 次数と詳細つり合い、シャッフルの式 = 総当たり（6 枚まで）、文脈ごとの確率の合計 = 1、前向き・後ろ向きの尤度 = 総当たり、一様化 = 行列の指数関数、MCMC の平均・分散・相関、2 項分布の定常分布と平均の戻り時間 2^N などを照合しています。ページランクはシリーズ 8 の 08 とシリーズ 31 の 11、待ち行列の出生死滅過程はシリーズ 29 の 05、イジング模型はシリーズ 55 の 11、ビタビのアルゴリズムはシリーズ 59 の 13、お手本の曲から作るマルコフ連鎖の作曲はシリーズ 7 の 08、行動を加えたマルコフ決定過程はシリーズ 63 で扱っています。
