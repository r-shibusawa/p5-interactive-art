# シリーズ45：機械工学 ─ p5.js コード集

機械を「動かす・支える・回す・熱を仕事に変える」しくみとして組み立てる。リンク・カム・歯車の機構、応力・はり・座屈の材料力学、共振と危険速度の機械力学、熱機関までを 2D の図と式で体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series45/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（13）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| リンクが「組み立てられない」（00・14） | b + c が短すぎる（または長すぎる）。● を動かすか `R` でリセット |
| 歯車が重なる・歯がぶつかる（04・05） | 04 は `Z` で 1 枚戻して置き直す。05 は `sunList` の歯数が組立条件 `(zs + zr) / 3 = 整数` を満たすか確認 |
| グラフが動かない・値が変わらない | まずキャンバスを 1 回クリックしてからキーを押す |
| 画面が固まる | 14 の `stepsPerFrame`、07 の `NB`、04 の歯車の枚数を減らす |
| `startAudio is not defined`・`makeGearOutline is not defined` | 一番下の「道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラなしでもマウスで動く） |

すべて 2D の簡易モデルです。式は機械工学の教科書（機構学・材料力学・機械力学・熱力学。Norton『Design of Machinery』、Gere『Mechanics of Materials』、Den Hartog『Mechanical Vibrations』など）と同じ形にしてあります。
