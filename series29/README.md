# シリーズ29：待ち行列理論 ─ p5.js コード集

レジ・窓口・コールセンター・道路の渋滞。「ランダムに来る客」と「ランダムにかかるサービス」から行列が生まれるしくみを、シミュレーションと公式の両方で確かめるワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series29/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（13）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `expRand is not defined` | 一番下の「道具」までコピーできていない → 全部コピーし直す |
| 測った値が理論とずれる | ρ が 1 に近いと平均が落ち着くまでとても長い。↑ で速くするか F で早送り、R で測り直す |
| 行列が伸び続ける | ρ = λ/(cμ) が 1 以上。λ を下げるか、μ や窓口の数を増やす |
| 画面が重い | 08 の「1 フレームの人数」、14 の部品や客の数を減らす |
| `startAudio is not defined` | 13 の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

公式は待ち行列理論の教科書（Kleinrock『Queueing Systems』、Harchol-Balter『Performance Modeling and Design of Computer Systems』など）と同じ形にしてあります。シミュレーションは教育用の簡易版です。
