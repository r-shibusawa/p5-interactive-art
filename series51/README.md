# シリーズ51：サイバネティクス ─ p5.js コード集

「動物と機械における制御と通信」（ウィーナー『サイバネティックス』1948）。結果が原因にもどってくる「円環的な因果」を、本物のシミュレーションで動かして見るワークショップ（110分）のコード集です。サーモスタットとワットの調速機の負のフィードバック、遅れが生む企図振戦、予測して狙う射撃から、アシュビーのホメオスタット・必要多様度の法則・ブラックボックス、グレイ・ウォルターの亀とブライテンベルクの乗り物、マカロック-ピッツのニューロン、オートポイエーシス、ビアの存続可能システム、互いを観察する系と固有形まで。最後は音と光の Musicolour とビデオフィードバックで作品に。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series51/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「サイバネティクスの道具」（グラフ・ブロック図・乱数・自己テスト、RK4・最小二乗など）があるので、**一番下まで全部コピー**する。🔊 音を使うスケッチ（14）は、実行したらまずキャンバスを1回クリック。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `plotLine is not defined` / `rk4 is not defined` / `lsqFit is not defined` | 一番下の「サイバネティクスの道具」までコピーできていない → 全部コピーし直す |
| 画面左下の「自己テスト」が ✗ になる | 道具の中の式や ★ の値を大きく変えた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 01 で回転がゆれ続ける | 摩擦 c が小さすぎるかゲイン kv が大きすぎる（ハンチング）。2 で摩擦を選んで ↑ |
| 04 がなかなか安定しない | 運がわるい配線の表。R で次の種にする。D で環境を変えた直後はしばらくさがす |
| 06 が「入力が足りない」のまま | 入力をほとんど動かしていない。A で自動入力にするか、左の帯で上下に大きく動かす |
| 10 で膜が直らない | こわれやすさ（↑↓）が大きすぎるか、K で触媒を止めている |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |

どのスケッチも本物のシミュレーションです。連続の系は 4 次のルンゲ＝クッタ法（00 のハウリング、01 の調速機）か小さなきざみのオイラー法（遅れのある系 02・11、ホメオスタット 04）で解き、ブロック図の信号の値・時間グラフ・ずれ・周期・振幅・取りかえ回数・多様度・エントロピーを画面に出しています。各スケッチは起動時に自己テストで、式で計算できる値と照合しています（サーモスタットの周期 = τ ln(…) の和、ハウリングの増え方 e^{2.5}、調速機の安定条件とシミュレーションの一致、Kτ = 1.6 での周期 ≈ 4τ、最小二乗の予測が直線・放物線を正確に先読み、ホメオスタットが種 3 で安定し見つけた重みが本当に安定、必要多様度の下限と全探索の一致、ARX が係数を 1e-6 以下の誤差で当てる、マカロック-ピッツの真理値表と記憶、人工化学の S + 2L の保存と膜の修復、cos の不動点 0.7390851332、ハウスドルフ距離が毎回半分以下 など）。
