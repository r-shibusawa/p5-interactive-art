# シリーズ30：オペレーションズ・リサーチ ─ p5.js コード集

限られた資源・時間・お金で「一番よい決め方」を探す。生産計画の線形計画法、整数計画と分枝限定法、輸送・スケジューリング・プロジェクト管理、在庫と不確かな需要、巡回セールスマンとメタヒューリスティクス、施設配置と配送計画、ゲーム理論までを体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series30/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（14）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 最適解が見つからない・何も起きない | スペースや A で「進める」スケッチが多い。上の 1 行目に操作が書いてある |
| 結果が毎回ちがう | 08 – 12 はランダムな問題・ランダムな探索。R で新しい問題、同じ問題でやり直すならスペース |
| 画面が固まる・重い | 町・個体・点を減らす（08・09 の町の数、10 の集団、11 の住宅地） |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

どのスケッチも小さな例題ですが、式とアルゴリズムは OR の教科書（Hillier & Lieberman『Introduction to Operations Research』、Winston『Operations Research』など）と同じ形にしてあります。シンプレックス法と双対はシリーズ 16、動的計画法とナップサックはシリーズ 12、最大流とマッチングはシリーズ 15 も見てください。
