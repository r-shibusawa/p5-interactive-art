# シリーズ32：タイリング ─ p5.js コード集

すき間なく・重ならずに平面を埋める。正多角形とアルキメデスの平面充填、エッシャー風の変形タイル、五角形、ペンローズ・タイルと黄金比、2023 年の「帽子」タイル、ドミノとパズル、双曲平面と球面までを、動かしながら体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series32/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（13・14）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| タイルの線が交差してぐちゃぐちゃ | 点を動かしすぎ。R で戻す（02・03）。04 は交差する位置には動かない |
| 画面が重い・固まる | タイルを大きく（↑）、分割の回数を減らす（05 の ↓）、08 の目標を小さく |
| 07 の探索が終わらない | 大きさを ↓ で小さくするか、スペースで別の順番から探し直す |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラなしでも代わりの模様で動く） |

07 の帽子のパッチは「すき間・重なりなし」だけを条件にした探索で作っています。論文（Smith, Myers, Kaplan, Goodman-Strauss 2023）の無限のタイリングは、メタタイル H・T・P・F の置き換えで作られます。
