# シリーズ54：電磁気学 ─ p5.js コード集

「電気力線はどうやって描くの？」「電波はどうやってアンテナから飛び出すの？」― 目に見えない電場と磁場を、物理の式から**本当に計算して**描き、動かすワークショップ（110分）のコード集です。クーロンの法則・電場と電位・ガウスの法則・導体とコンデンサ（静電気）から、キルヒホッフの法則・RC 回路・RLC の共振（回路）、電流のつくる磁場・ローレンツ力・電磁誘導・モーターと発電機（磁気）、マクスウェル方程式を解く FDTD・アンテナからの電波・電磁波のスペクトル（電磁波）まで。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series54/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「電磁気の道具」（場の計算・緩和法・RK4・矢印やグラフを描く道具・自己テスト）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**（ヘッドホンは特に注意）。📷 カメラ（15）はアドレスバーで許可する
5. 左下の「自己テスト ✓ n / n」は、計算が式どおりになっているかを起動時に確かめた結果

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `fieldAt is not defined` / `marchingSquares is not defined` / `selfTestLine is not defined` | 一番下の「電磁気の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 画面左下の「自己テスト」が ✗ になる | 道具の中の式や定数（KC、EPS0、MU0 など）を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 03・15 の色がなかなか落ち着かない | 緩和法は何回もならして答えに近づく。OMEGA（1〜2 未満）や 1 フレームの回数を大きくすると速い |
| 11 の波が爆発して画面が真っ赤・真っ青 | SC（クーラン数）を 1/√2 = 0.707 より大きくした → 0.5 にもどす |
| 音が出ない・大きすぎる | キャンバスをクリック ／ すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |
| カメラが動かない | アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |

場はどれも手で描いていません。点電荷の重ね合わせ（クーロンの法則）、電気力線は E の向きをルンゲ・クッタ法（RK4）でたどり、等電位線は格子のマーチング・スクエア、導体とカメラの電位はラプラス・ポアソン方程式の SOR 法、回路は修正節点解析の連立方程式（ガウスの消去法）、RC・RLC は RK4、磁場はまっすぐな電流の部分ごとのビオ・サバールの正確な式の和、荷電粒子はボリス法、電磁誘導の磁束はベクトルポテンシャルの線積分 ∮A·dl、電磁波は FDTD（ヤジー格子、ムーアの吸収境界）、アンテナはヘルツの双極子の解析解で計算しています。各スケッチは起動時に自己テストで、距離 2 倍で力 1/4、双極子の軸の上の E、円を通る電束 = q/ε0（1% 以内）、平行板の C = ε0·w/d、同軸の C = 2πε0/ln(b/a)、手で計算した回路の電流と電流則、RC の 63.2%、LC の周期とエネルギー保存、円電流の中心の μ0I/2R、アンペールの法則、サイクロトロンの周期と半径、∫V dt = −NΔΦ、FDTD の波の速さ = c と共振器の周期、放射の sin²θ、c = fλ、E = hf などの式と照合しています。2 次元の計算（02・03・11・15）は「紙に垂直な方向に長い」ものの断面です。
