カオス
コード集

きまりがあるのに予測できない。ロジスティック写像、二重振り子、ローレンツの蝶。コピーして p5.js Web Editor に貼り付けるだけで、カオスを自分の手で起こせます。

p5.js Web Editor を開く → ZIP でダウンロード
01番号を開いて「コードをコピー」
02エディタの sketch.js を全部消して貼り付け
03左上の ▶ で実行
04音のスケッチは一番下の道具までコピーして、まずクリック
