# シリーズ4：カオス ─ p5.js コード集

「きまりがあるのに予測できない」カオスを、1行の式・振り子・ストレンジ・アトラクターで体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series4/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音・🎤 マイクを使うスケッチは、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 数が `NaN` や `Infinity` になる・消える | 計算が発散した。`dt` を小さく、初期値を変える、クリックでリセット |
| 画面が重い | 点の数（`N`、`count`、1フレームの計算回数）を減らす |
| `startAudio is not defined` など | 一番下の「道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・マイクが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

音を使うスケッチ（10〜12, 15）は p5.sound ではなく、ブラウザ標準の **Web Audio API** を使っています（p5.js 1.x / 2.x どちらでも動きます）。
