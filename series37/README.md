# シリーズ37：離散モース理論 ─ p5.js コード集

山と谷と峠だけで「形」が決まる。なめらかなモース理論（高さ関数の臨界点）から、フォルマンの離散モース理論（胞体複体の上の矢印）へ。勾配ベクトル場・崩壊・モース不等式・パーシステンスによる簡略化を、格子と地形と画像の上で体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series37/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. ほとんどのスケッチは一番下に「離散モース理論の道具」がある。**コードは最後まで全部コピー**する。🔊 音を使うスケッチ（13）は、実行したらまずキャンバスを1回クリック。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `makeGridComplex is not defined` | 一番下の「離散モース理論の道具」までコピーできていない → 全部コピーし直す |
| 赤い胞体が消えない（02） | その胞体の面・余面の値を見る。「小さい余面」「大きい面」はそれぞれ高々 1 つ |
| 閉路が消えない（04） | ランダムな矢印は勾配場ではない。G で高さ関数から作り直す |
| 画面が固まる・カクつく | 格子を小さく（`nx`, `ny`）。09・14 はブラシを小さく、11 は `nx`, `ny` を 64×48 に |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

勾配場は Robins・Wood・Sheppard（2011）の lower star 法、キャンセルはフォルマンの定理（V-パスがただ 1 本のペアを逆向きに）で実装しています。ベッチ数は Z2 係数で、b0 は Union-Find、b2 は閉じた曲面の数、b1 = b0 + b2 − χ です。
