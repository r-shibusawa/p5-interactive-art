# シリーズ69：数理論理学 ─ p5.js コード集

「正しい推論」を記号と規則だけで扱い、論理そのものの力と限界を調べる ― **数理論理学**を自分で動かして確かめるワークショップ（110分）のコード集です。真理値表と標準形、自然演繹の証明チェッカー、導出原理から始めて、量化子と有限モデル、単一化と論理プログラミング（Prolog）、意味のタブロー、ペアノ算術と数学的帰納法、ラムダ計算、カリー-ハワード対応、ゲーデル数、対角線論法と不完全性定理、様相論理とクリプキモデル、正直者とうそつきのパズル、そして音とカメラまで、どれも**ライブラリを使わずに本当に計算した**シミュレーションです。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「論理の道具」（論理式の構文解析・文字列化・真理値表、CNF / DNF の書きかえ、木の描き方、ラムダ計算の簡約、自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. 論理式の書き方：¬ ∧ ∨ → ↔ はキーボードでは `~` `&` `|` `->` `<->`（`!` `^` `>` `=` でも可）。`1` = ⊤（真）、`0` = ⊥（偽）、変数は小文字 1 字（p q r …、p1 のように数字をつけてもよい）。強さの順は ¬ ＞ ∧ ＞ ∨ ＞ → ＞ ↔ で、→ は右から（p→q→r = p→(q→r)）。ラムダ式（08・09）は `\` が λ、数字がチャーチ数、大文字が名前つきの式（PLUS TIMES TRUE K S など）
6. 文字を入力するスケッチ：00・01・06・08・09・10 は文字キーがいつも入力で、操作は ↑↓ ← → Enter Tab Backspace Esc だけ。14・15 は **Tab で編集モード**に切りかえてから入力（編集中は文字キーがすべて入力になり、ほかの操作キーは効かない。Enter か Tab で終わる）。まちがった式を打っても赤い説明が出るだけで、前の正しい式のまま動く

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `parseFormula is not defined` / `lamParse is not defined` | 一番下の「論理の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す。14・15 は Tab で編集モード ⇔ ふつうのモードを切りかえる |
| 文字を打つと勝手に操作される／操作キーが効かない | 00・01・06・08・09・10 と、14・15 の編集モードでは文字キーはすべて入力。操作は矢印キー・Enter・Tab・Esc。14・15 は Enter か Tab で編集モードを終わる |
| 式が赤い「まちがい」になる | かっこの数、演算子が 2 つ続いている、`-` だけ（`->` と書く）、大文字の変数、変数が 7 個以上、など。説明の「何文字目あたり」を見る。直すまでは前の式のまま動く |
| 02 の証明で規則がはねられる | 選ぶ行の順番（→E は「A → B」と「A」）、閉じた箱の中の行を外で使っていないか、仮定・∨I・⊥E の式を候補から選んだか。H でお手本 |
| 画面右下の「自己テスト」が ✗ になる | 道具や表（規則・プログラム・お手本の答え）を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくても領域のクリックで動く。C で切りかえ） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

アルゴリズムはすべてゼロから実装しています：再帰下降の論理式パーサ（ASCII の別名、まちがいの説明つき）と真理値表、外側・左からの 1 か所ずつの書きかえによる CNF / DNF、フィッチ式の自然演繹のチェッカー（箱＝スコープの計算と規則の形の検査）、幅優先の飽和による導出原理、有限モデルでの一階の式の評価、ロビンソンの単一化（出現検査つき）と深さ優先の SLD 導出、α 規則優先の意味のタブロー、パターン照合によるペアノ算術の書きかえと帰納法の証明の検査、変数の捕獲をさける置きかえによる β 簡約（正規順序と作用的順序）、単一化による型推論と直観主義の証明探索（ループ検出で有限）、BigInt のゲーデル数と素因数による復号、クリプキモデルでの □ ◇ の評価、正直者とうそつきの総当たり。各スケッチは起動時に自己テストで、でたらめな式の文字列化 → 読み直しの一致、ド・モルガン・排中律・パースの法則が恒真で p ∧ ¬p が矛盾、CNF / DNF が全部の割り当てでもとの式と同値、自然演繹のお手本を認めてまちがった行をはねること（でたらめにボタンを押して作った行も真理値表で健全）、導出で □ が出る ⇔ 総当たりで充足不能、∀∃ と ∃∀ の評価が二重ループの直接計算と一致、単一化子で両辺が等しくなり X = f(X) が失敗、家系図の先祖の答え、タブローと真理値表の恒真の判定の一致、2 + 3 → s⁵(0) と 2 × 3 → s⁶(0)、PLUS 2 3 → 5 と TIMES 2 3 → 6 と Ω が上限に当たること、K・S・合成の型、ゲーデル数の往復、対角線の列がどの行ともちがうこと、世界 3 個までの全部のフレームで T ⇔ 反射的・4 ⇔ 推移的など、パズルの答え = 総当たり、などを照合しています。SAT の探索（DPLL）と 3-CNF への変換はシリーズ 18 の 03・04、ブール代数と論理回路はシリーズ 56 の 06、チューリング機械と忙しいビーバーはシリーズ 66 の 10・11、ファジィ論理はシリーズ 50 で扱っています。
