# シリーズ62：決定木 ─ p5.js コード集

「はい/いいえ」の質問を重ねてデータを分ける、いちばん説明しやすい機械学習 ― 決定木を**自分の手で作って確かめる**ワークショップ（110分）のコード集です。20 の質問とエントロピー・情報利得から始めて、手で作る木、ID3 と「テニスをする？」の表、CART と領域分割、深さと過学習、コスト複雑度剪定と交差検証、回帰木、そしてバギング・ランダムフォレスト・AdaBoost・勾配ブースティング、特徴量の重要度、ほかの方法との境界の比べ方まで、どれも**ライブラリを使わずに本当に学習した**シミュレーションです。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series62/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「決定木の道具」（エントロピーとジニ、CART、回帰木、剪定、フォレスト、ブースティング、木の図、自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. 色：クラス A = オレンジ、B = 青、C = 緑。木の図は「x1 ≤ しきい値？」に「はい」なら左、「いいえ」なら右。[A|B] はそのノードの件数

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `growTree is not defined` / `drawTree is not defined` | 一番下の「決定木の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 画面右下の「自己テスト」が ✗ になる | 道具の中の式やデータ（00 の動物の表、03 のテニスの表など）を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 08・09・12 のグラフが少しずつしか伸びない | 重くならないように、木を 1 フレームに 1〜2 本ずつ育てている（数秒で終わる） |
| 木の図が点だけになる | 葉が多くて文字が入らない。深さ（← → や ↑↓）を小さくすると文字が出る |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

学習の手順はすべてゼロから実装しています：エントロピー・ジニ・誤分類率、情報利得と利得比、カテゴリの属性の ID3、並べた値の中点を全部調べる CART（深さ・最小の点の数で停止）、いちばん弱い枝から刈るコスト複雑度剪定と k 分割交差検証、2 乗誤差の回帰木、ブートストラップ、特徴量を間引くランダムフォレストと OOB 誤差、切り株の AdaBoost（2 クラスの SAMME）、縮小つきの勾配ブースティング（2 乗誤差）、不純度の減少と並べ替えによる重要度。データはすべて種つきの乱数で作った合成データ（「テニスをする？」の 14 行の表だけは有名な例）です。各スケッチは起動時に自己テストで、エントロピー(0.5) = 1・ジニの最大 0.5、情報利得 ≥ 0、テニスの表の 9 / 5 と天気の利得 0.2467、CART の分割 = 全部のしきい値の総当たり、最後まで育てた木は訓練 100%、α の列が増える・葉の数が減る、回帰木の SSE の減り、ブートストラップの約 63.2%、OOB 誤差 ≈ テスト誤差、AdaBoost の上限 Π 2√(ε(1−ε))、勾配ブースティングの訓練誤差が単調に減る、乱数の列の並べ替え重要度 ≈ 0、斜めの境界は深さ 3 の木では表せずロジスティック回帰は 98% 以上、などを確かめています。同じ「決定木」でも、比較による並べかえの下限（n log n）はシリーズ 10 の 09、情報のエントロピーそのものはシリーズ 6 の 01 で扱っています。
