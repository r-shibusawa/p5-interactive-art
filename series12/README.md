# シリーズ12：動的計画法・貪欲法・償却解析 ─ p5.js コード集

小さな答えを表に貯めて大きな答えをつくる「動的計画法（DP）」、その場で一番よいものを選び続ける「貪欲法」、たまに高くつく操作を平均でならす「償却解析」。アルゴリズム設計の 3 つの道具を、表が 1 マスずつ埋まっていくアニメーションで体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

参考：Cormen ほか『Introduction to Algorithms』

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series12/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. ほとんどのスケッチは **スペース = 再生・停止、→ = 1 手ずつ、R = 最初から**。🔊 のスケッチは一番下の「道具」まで全部コピーして、まずキャンバスを 1 回クリック

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 何も動かない | スペースで再生になっているか確認。→ で 1 手ずつ進められる |
| 画面が重い | 表を小さくする（文字列を短く、n を小さく）。14 は `IW`・`IH` を小さく |
| 矢印キーが効かない | キャンバスを 1 回クリックしてから押す（エディタのコード欄に入力されている） |
| `startAudio is not defined` | 一番下の「音の道具」までコピーできていない → 全部コピーし直す |
| 音が出ない | キャンバスを 1 回クリック ／ 端末の音量を確認 |
