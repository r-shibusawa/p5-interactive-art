# シリーズ44：流体力学 ─ p5.js コード集

水や空気の「流れ」を自分の手で動かす。流線の見方から、連続の式・ベルヌーイの定理、ポテンシャル流と翼の揚力、そして粘性と**ナヴィエ・ストークス方程式**を実際に数値で解いて、渦・乱流・波までを体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（13）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する

## ナヴィエ・ストークス方程式

このシリーズの中心になる式です（非圧縮性の流体）。

```
∂u/∂t + (u·∇)u = −(1/ρ)∇p + ν∇²u + f ,　　∇·u = 0
        └ 移流 ┘   └ 圧力 ┘   └ 粘性 ┘  └ 外力     └ 非圧縮（連続の式）
```

07 では格子の上で「① 外力 → ② 粘性（拡散）→ ③ 移流 → ④ 圧力（射影）」の順に本当に解き、各項を 1〜4 キーで ON/OFF できます（Stam の Stable Fluids）。08・13・14・15 は同じソルバー、10 は渦度・流れ関数の形、09 は格子ボルツマン法（マクロにはナヴィエ・ストークス方程式にしたがう）で解いています。

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 流れが出ない・すぐ止まる | 粘性 `nu` が大きすぎる。下キーで小さく。07 は 1〜4 が全部 ON か確認（R でやり直し） |
| 画面が固まる・カクカクする | 格子を小さく（`NX` を 96、09 の `nx` を 120、`stepsPerFrame` を 4 に） |
| 09 の渦がなかなか出ない | 10 秒ほど待つ。Re が 50 より小さいと出ない（上キー） |
| 計算がこわれて模様がちらつく | 09 は `U0` を 0.1 以下に、12 は水深を 1.6 以下に。R でやり直し |
| `startAudio is not defined`・`IX is not defined` | 一番下の「道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

すべて 2D・あらい格子の簡易シミュレーションです（数値粘性があるので、実効レイノルズ数は表示より低めです）。式は流体力学の教科書（今井功『流体力学（前編）』、Kundu & Cohen『Fluid Mechanics』、Stam "Stable Fluids" 1999 など）と同じ形にしてあります。
