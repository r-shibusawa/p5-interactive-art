錯視
コード集

見えているもの ≠ そこにあるもの。長さ・大きさ・傾き、明るさと色、動きと残像、主観的輪郭と不可能図形をプログラムで作り、「真実を見る」（T キー）で本当に同じかを画素で確かめます。調整法で自分の錯視の強さを測り、音とカメラにも広げます。

p5.js Web Editor を開く → ZIP でダウンロード
01番号を開いて「コードをコピー」
02エディタの sketch.js を全部消して貼り付け
03左上の ▶ で実行
04どれも一番下の「錯視の道具」まで全部コピー。音（14）はまずクリック
