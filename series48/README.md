# シリーズ48：錯視 ─ p5.js コード集

見えているもの ≠ そこにあるもの。同じ長さの線、同じ灰色、同じ大きさの円が、まわりの模様しだいで違って見える「錯視」を、プログラムで作って確かめるワークショップ（110分）のコード集です。長さ・大きさ・傾きの錯視、明るさと色の錯視、動きと残像、主観的輪郭と不可能図形、そして音とカメラまで。どのスケッチにも「真実を見る」（T キー）があり、比べている 2 つが本当に同じであることを画素を読んで確かめられます。調整法（心理物理学の測り方）で、自分の錯視の強さを数字で記録します。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series48/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「錯視の道具」（画素を読む・自己テスト）があるので、**一番下まで全部コピー**する。🔊 音を使うスケッチ（14）は、実行したらまずキャンバスを1回クリック。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `readPix is not defined` / `selfTestLine is not defined` | 一番下の「錯視の道具」までコピーできていない → 全部コピーし直す |
| 画面左下の「自己テスト」が ✗ になる | 比べる 2 つの色や長さ（G・L0・DARKV など）を片方だけ書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| Enter で記録されない | キャンバスを1回クリックしてからキーを押す |
| 錯視が見えない・弱い | 個人差があるのがふつう。画面から少し離れる、T（真実）を切る、パラメータ（★）を変える |
| 09・10・11・15 で目が疲れた・気分が悪い | **長く見つめて気分が悪くなったら目を離す**。休んでから続ける。10 の回転は明暗の切りかわりが 1 秒に 3 回までに制限してある |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |

## 本当に同じ？ ─ 自己テストで確かめていること

錯視のスケッチは、比べる 2 つを 1 つの定数（同じ長さ・同じ灰色・同じ色）から作り、起動時に描いた画面の画素を読んで、本当に同じであることを確かめています（画面左下の「自己テスト ✓」）。たとえば 00 は 2 本の線の長さを画素で数え、04・05・07 は 2 つの的の RGB を読み比べ（05 は影の倍率 = 黒マス ÷ 白マスなので影の中の白マスと日なたの黒マスが 1 の位まで一致）、06 は 1 行の画素をすべて読んで左右の面が同じ 128 であることを、08 は交差点と道の真ん中がどちらも白 255 であることを、12 は三角形の中とふちが背景と同じ値であることを確かめます。13・14 のように「同じに見える理由」が計算にあるスケッチは、射影（ペンローズの三角形は魔法の角度で端と端が 0 px に重なる）やシェパード音の倍音の構成（1 オクターブ上がると同じ組に戻る）を検算しています。

図はすべて、錯視の仕組みからプログラムで作ったオリジナルです（特定の作品の再現ではありません）。
