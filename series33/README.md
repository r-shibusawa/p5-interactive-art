# シリーズ33：貴金属比 ─ p5.js コード集

黄金比 φ、白銀比 1+√2、青銅比 …… 長方形から正方形を n 枚取ると同じ形が残る「貴金属比」φn = (n + √(n²+4)) / 2 の仲間たちを、連分数・数列・螺旋・紙・植物・準結晶・音で体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

> **「白銀比」は 2 種類あります。** 日本で昔から「白銀比（大和比）」と呼ばれるのは √2 ≈ 1.414（A 判の紙）。数学の「貴金属比」の 2 番目（n = 2）も白銀比と呼ばれ、こちらは 1+√2 ≈ 2.414。さらに 1+√3 ≈ 2.732 を「第2白銀比」と呼ぶこともあります。どれも正しい呼び名なので、文脈で区別しましょう（スケッチ 00）。

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 数字が `NaN` や `Infinity` になる | 0 で割っていないか確認。連分数（02）や数列（03）の項の数を増やしすぎると小数の精度が足りなくなる |
| 画面が重い | 種の数（07 の `N`）、分母の上限（08 の `Qmax`）、線の本数（11 の `K`）、絵の大きさ（12 の `sizes`）を小さく |
| 螺旋や渦がずれて見える | 比が貴金属比からずれている。`metallic(n)` の式と n の値を確認 |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

式は整数論・力学系の教科書（Hardy & Wright『数論入門』、Baake & Grimm『Aperiodic Order』など）と同じ形にしてあります。11 は置換規則の代わりに de Bruijn の多重格子法で、同じ仲間（正方形とひし形の八回対称）のタイリングをつくっています。
