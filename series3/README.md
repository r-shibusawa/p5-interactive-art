# シリーズ3：人工生命（ALife）─ p5.js コード集

「生きているとはどういうことか」を、単純なルールのくり返しから生まれる動きで考えるワークショップ（110分）のコード集です。
セル・オートマトン、群れ、生態系、進化を、自分の手で動かして観察します。[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series3/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音・🎤 マイクを使うスケッチは、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 画面が固まる・重い | セルの数や粒の数を減らす（`cellSize` を大きく、`n` を小さく） |
| 全部死んでしまう・増えすぎる | 確率やエネルギーの数字を少しずつ変えて、バランスを探す（それ自体が実験） |
| `startAudio is not defined` など | 一番下の「道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・マイクが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

音を使うスケッチ（10〜12）は p5.sound ではなく、ブラウザ標準の **Web Audio API** を使っています（p5.js 1.x / 2.x どちらでも動きます）。
