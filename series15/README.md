# シリーズ15：フロー・マッチング・並列・オンライン ─ p5.js コード集

水をどれだけ流せるか（最大フロー）、誰と誰を組ませるか（マッチング）、みんなで同時に計算するには（並列）、未来を知らずにどう決めるか（オンライン）。
それぞれのアルゴリズムを、動かして確かめるワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

参考：Cormen ほか『Introduction to Algorithms』

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series15/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチは、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 画面が重い | 点の数を減らす（04・05・07 は上下キーで小さく） |
| `startAudio is not defined` など | 一番下の「道具」までコピーできていない → 全部コピーし直す |
| 増加道が見つからない | s から t へ矢印の向きにたどれる道があるか確認（14 は矢印の向きに注意） |
| 音が出ない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

コードは教育用に書き下ろした簡易実装です。
