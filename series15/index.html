フロー・マッチング
並列・オンライン

水をどれだけ流せるか（最大フロー）、誰と誰を組ませるか（マッチング）、みんなで同時に計算するには（並列）、未来を知らずにどう決めるか（オンライン）。それぞれのアルゴリズムを、動かして確かめます。

p5.js Web Editor を開く → ZIP でダウンロード
01番号を開いて「コードをコピー」
02エディタの sketch.js を全部消して貼り付け
03左上の ▶ で実行
04音のスケッチは一番下の道具までコピーして、まずクリック
