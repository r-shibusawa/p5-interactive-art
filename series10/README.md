# シリーズ10：ソートと計算量 ─ p5.js コード集

参考：Cormen ほか『Introduction to Algorithms』

アルゴリズムの「速さ」を目で見て、耳で聞く。挿入ソート・マージソートから、分割統治、乱択、ヒープ、クイックソート、比較しないソート、選択問題までを体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series10/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 多くのスケッチは **スペースで再生／停止、→ で 1 手ずつ、↑↓ で速さ**。🔊 のスケッチは一番下の「道具」まで全部コピーして、まずキャンバスをクリック

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 動きが速すぎて見えない | ↓ キーで遅くする／スペースで止めて → で 1 手ずつ |
| 画面が重い | `n`（要素数）を小さくする |
| `startAudio is not defined` | 一番下の「道具」までコピーできていない → 全部コピーし直す |
| 音が出ない | キャンバスを1回クリック ／ 端末の音量を確認 |

配列の添字は JavaScript に合わせて **0 始まり** です。
