# シリーズ31：不動点定理 ─ p5.js コード集

写像で動かしても「動かない点」＝不動点。くり返すと吸い込まれる不動点（バナッハの縮小写像の原理）と、連続でさえあれば必ず存在してしまう不動点（ブラウワーの不動点定理）を、クモの巣図・自己相似図形・部屋の地図・コーヒー・ゲーム・ページランク・微分方程式で体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series31/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（13・14）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 反復の点が画面の外へ飛んでいく | 縮小写像になっていない（01 の \|f'\| > 1、02 の k ≥ 1、14 の赤い枠）。値を小さく |
| 画面が固まる・重い | 点や回数を減らす（05 の `maxPts`、14 の `iterPerFrame`・深さ、08 の n、15 の `FW`） |
| 不動点が見つからない・十字が出ない | 写像が箱（円板・三角形）からはみ出している。`constrain` を外していないか確認 |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

数学の背景は、バナッハの不動点定理（縮小写像の原理）、ブラウワーの不動点定理とスペルナーの補題、ナッシュ均衡の存在証明、ピカール＝リンデレーフの定理です。シリーズ27（トポロジー）の 11・12、シリーズ8（グラフ）の 08 ページランクと合わせて読むと、同じ定理を別の角度から見られます。
