文字列・計算幾何・
機械学習 コード集

文字列の中から言葉を探し、点と線分の形を計算し、データから学ぶ。文字列照合・計算幾何学・機械学習のアルゴリズムを、動かしながら体験します。

p5.js Web Editor を開く → ZIP でダウンロード
01番号を開いて「コードをコピー」
02エディタの sketch.js を全部消して貼り付け
03左上の ▶ で実行
04文字列はキーで入力、Tab で切りかえ。音は一番下の道具までコピー
