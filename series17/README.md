# シリーズ17：文字列・計算幾何・機械学習 ─ p5.js コード集

文字列の中から言葉を探す、点や線分の「形」を計算する、データから学ぶ。文字列照合・計算幾何学・機械学習のアルゴリズムを、動かして体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

参考：Cormen ほか『Introduction to Algorithms』

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series17/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 文字列のスケッチ（00〜04）は、キーボードでそのまま文字を入力できます。**Tab** でテキストとパターンを切りかえ
5. 🔊 音を使うスケッチは、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 文字が入力できない | キャンバスを1回クリックしてからキーを押す。日本語入力（IME）はオフにする |
| 数字キーで文字が入らない | 00・02〜04 では 1〜4 がお手本の切りかえ。01 は数字も入力できる（お手本は ←） |
| 動きが速すぎる・遅すぎる | `speed`（何フレームに 1 回）や ↑↓ キーで調整 |
| `startAudio is not defined` | 一番下の「道具」までコピーできていない → 全部コピーし直す |
| 音が出ない | キャンバスを1回クリック |

計算幾何のスケッチは、画面の y 軸が下向きなので、外積の計算では y を反転して「数学の向き（左回り = +）」にそろえています。
