シリーズ 19〜21 は画像処理（モルフォロジー）・制御工学・ロボティクス、22〜25 はボロノイ図・群と対称性・力学・量子力学を扱います。

各シリーズは 110 分の授業を想定した 16 本のスケッチと、進め方の説明（各フォルダの README）で構成されています。
