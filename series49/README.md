# シリーズ49：最適化理論 ─ p5.js コード集

坂を下る速さを、計算で確かめる。凸性と最適性条件から、最急降下法・直線探索・慣性とネステロフの加速・確率的勾配法と Adam、ニュートン法・BFGS・共役勾配法、ラグランジュ乗数・KKT 条件・ペナルティ法と内点法、LASSO・非凸と鞍点・最速降下線まで、本物の関数と本物の勾配で計算し、収束率の理論値と実測を並べるワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `PAL is not defined` / `contourImage is not defined` | 一番下の「最適化の道具」までコピーできていない → 全部コピーし直す |
| 画面左下の「自己テスト」が ✗ になる | 関数・勾配・ヘッセ行列の式や定数を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 数字のかわりに「発散」と出る | ステップ幅が大きすぎる（2/L より大きい）か、ニュートン法が遠くから出発した。↓ で小さく、06 は D で減衰ニュートン |
| 収束のグラフが途中で消える | f − f* が 10⁻³⁰ より小さくなった（計算の精度の限界）。正常 |
| 05・13・14 が重い | 色分けや最適化は少しずつ計算している。しばらく待つか、★ のデータ数・格子を小さく |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |

勾配とヘッセ行列はすべて式で書き、起動時の自己テストで差分（数値微分）と照合しています。収束率は前提（ステップ幅の決め方、f − f* と ‖x − x*‖ のどちらを測るか、強凸かどうか）と一緒に表示し、理論が等号を与えるもの（2 次関数での最急降下 ((κ−1)/(κ+1))²、共役勾配法が n 回で終わる、ニュートン法が 2 次関数を 1 回で解く、内点法の双対ギャップ = mμ など）は等号で、上限しか言えないもの（O(1/k)、O(1/k²)、共役勾配法の 2((√κ−1)/(√κ+1))^k など）は毎回「上限以下」かを確かめています。
