# シリーズ2：フラクタル ─ p5.js コード集

「同じ形がどこまでも続く」フラクタルを、再帰・自己相似・複素数の順にたどりながら、自分の手で動かして遊ぶワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series2/**

「コードをコピー」→ エディタに貼り付け → ▶ で実行。「動かしてみる」でお手本の動きも確認できます。

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音・🎤 マイクを使うスケッチは、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする
5. 🎤 マイクはブラウザの許可ダイアログで「許可」を選ぶ

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 画面が固まる・重い | 深さ（depth）や点の数を減らす。08 は `maxIter`、09・15 は `w, h` を小さく |
| `Maximum call stack size exceeded` | 再帰の「終わる条件」が抜けている（`if (len < 5) return;` など）|
| `startAudio is not defined` など | 一番下の「道具」までコピーできていない → 全部コピーし直す |
| 音が出ない | 一度キャンバスをクリックする / PC の音量を確認 |
| マイクが動かない | アドレスバー左の鍵マークから許可を「オン」にして再実行 |

## 音のしくみについて

音を使うスケッチ（10〜12, 15）は p5.sound ではなく、ブラウザ標準の **Web Audio API** を使っています。各ファイルの一番下に「道具」（`playNote()`, `getMicLevel()` など）があり、p5.js のバージョン（1.x / 2.x）に関係なく動きます。
