天体
地球と宇宙
コード集

足元の地球から宇宙の果てまで、計算で確かめる天文学。昼夜と季節、月の満ち欠けと食、潮汐、星空の回転から、軌道要素で計算する惑星の位置と逆行、ホーマン軌道とスイングバイ、黒体放射と星の色、HR 図、距離のはしご、系外惑星、銀河の回転曲線と宇宙の膨張まで。実際の式と実際のデータ（おおよその値）で計算し、数字はすべて画面に出します。どのスケッチも起動時に自己テストで計算を確かめます。

p5.js Web Editor を開く → ZIP でダウンロード
01番号を開いて「コードをコピー」
02エディタの sketch.js を全部消して貼り付け
03左上の ▶ で実行
