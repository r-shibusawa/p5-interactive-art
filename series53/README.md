# シリーズ53：天体（地球と宇宙） ─ p5.js コード集

足元の地球から宇宙の果てまで、**計算で確かめる天文学**。昼と夜・季節、月の満ち欠けと日食・月食、潮汐、星空の回転から、軌道要素とケプラー方程式で計算する惑星の位置と逆行、ホーマン軌道とスイングバイ、黒体放射と星の色、HR 図、距離のはしご、系外惑星、銀河の回転曲線と宇宙の膨張まで。実際の式と実際のデータ（おおよその値）で計算し、数字はすべて画面に出すワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series53/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「天文の道具」（ユリウス日、軌道要素とケプラー方程式、グラフ、自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. 画面の左下（07 は右下）の「自己テスト ✓ n / n」は、起動時に計算を手で確かめられる値と照合した結果。✓ なら計算は正しく動いている

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `planetPos is not defined` / `jdFromDate is not defined` | 一番下の「天文の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 画面の隅の「自己テスト」が ✗ になる | 式やデータを書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 04・05 で日付が進まない | 軌道要素が使えるのは 1800〜2050 年。範囲の外へは進まない |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくても V でテスト画像） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

惑星の位置は JPL の近似軌道要素（J2000、1800〜2050 年で誤差は数分角程度）からケプラー方程式をニュートン法で解いて、星の位置は J2000 の赤経・赤緯から恒星時で地平座標に、潮汐力は月と太陽の引力と中心の引力の差で、スイングバイは運動方程式の RK4 で、星の色はプランクの式に CIE 1931 の色合わせ関数の近似式を掛けて積分して、すべて画面の数字のとおりに計算しています。各スケッチは起動時に自己テストで、春分の昼 = 12 時間、北緯 35° の夏至の南中高度 78.44°、北極圏の極夜、J2000.0 = JD 2451545.0、地球の近日点は 1 月はじめ、2020-10-13 の火星の衝と 2020-12-21 の木星・土星の大接近、2024-04-08 の日食と 2025-03-14 の月食、8 惑星の T² / a³ = 1、ホーマン軌道 259 日、λmax·T = 2.898 × 10⁻³ m·K、太陽の光度 3.83 × 10²⁶ W、ラプラスの関係などの確かめられる値と照合しています。月や惑星の平均の動きを使う所（01・05 の周転円・06・14）は円軌道の近似、星や銀河の値はおおよその値です。
