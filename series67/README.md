# シリーズ67：情報幾何学 ─ p5.js コード集

確率分布を「点」と見て、分布の集まりを曲がった空間（多様体）として調べる ― **情報幾何学**を、見て・動かして・確かめるワークショップ（110分）のコード集です。確率の三角形と KL ダイバージェンス、フィッシャー情報とクラメール-ラオの限界、双曲平面になる正規分布の族から始めて、指数型分布族の 2 つの座標（θ と η）、e-測地線と m-測地線、ピタゴラスの定理と射影、ブレグマン・ダイバージェンス、自然勾配、EM 法、最大エントロピー、α-ダイバージェンス、相互情報量、球の上のフィッシャー-ラオ距離、そして音とカメラまで、どれも**ライブラリを使わずに本当に計算した**シミュレーションです。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series67/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「情報幾何の道具」（エントロピー・KL・フィッシャー-ラオ距離・α-ダイバージェンス、e と m の測地線、確率の三角形の座標と等高線、棒グラフ、正規分布の測地線、連立方程式、自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. 図の読み方：三角形の中の点 = 3 つの結果の確率分布（頂点 = 必ずその結果、まん中 = 3 つが同じ確率）。オレンジ = m（確率を混ぜる）側、紫 = e（対数で混ぜる）側、緑 = フィッシャー-ラオの測地線や「ぴったり 0」の確かめ。KL は「ナット」（自然対数）と「ビット」（log₂）の両方が出てくる

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `divKL is not defined` / `simplexFrame is not defined` | 一番下の「情報幾何の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 点や棒が動かない | 点（丸）の上から押してドラッグする。03・05・11 は点のすぐ近くを押す。12 はマス目を上下にドラッグ。13 は左下の三角形の中をドラッグ（それ以外のドラッグは視点の回転） |
| 値が `∞` になる | q のどこかが 0 で p がそこに確率を持つと KL は ∞（01 の右の等高線の辺）。点を辺から少し離す |
| 画面右下の「自己テスト」が ✗ になる | 道具や ★ の数字を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 13 が重い・真っ黒 | 3D（WEBGL）が使えないブラウザ。Chrome か Edge で開く |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く。C で切りかえ） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

計算はすべてゼロから実装しています：エントロピーと KL ダイバージェンス（0·log 0 = 0 と log 0 の扱い）、確率の三角形の重心座標と等高線、スコアの分散としてのフィッシャー情報（厳密な和とモンテカルロ）、コイン投げの最尤推定のくり返し、正規分布のフィッシャー計量の測地線（閉じた式・半楕円の数値積分・クリストッフェル記号の測地線方程式の RK4）、指数型分布族の ψ・η = ∇ψ・ルジャンドル変換 φ、e/m/α-測地線、ニュートン法による e-射影と最大エントロピー、周辺分布の積による m-射影、ブレグマン・ダイバージェンスと 2 種類の中心、フィッシャー行列の連立方程式を解く自然勾配、EM 法と自由エネルギー、α-ダイバージェンスと正規分布での近似（パターン探索）、反復比例あてはめ（IPF）による 3 変数の分解、球への写像 p → 2√p と大円。各スケッチは起動時に自己テストで、KL ≥ 0 と向きのちがい・三角不等式の反例、スコアの分散 = 1/(p(1−p)) と KL の 2 階微分、最尤推定の分散がクラメール-ラオの限界の 5% 以内、正規分布の距離の公式 = 数値積分 = RK4 の測地線（1e-4）、η = ∇ψ と ψ + φ − θ·η = 0、ピタゴラスの定理の両方の形（m-射影と e-射影、誤差 1e-10）、x log x のブレグマン = KL と中心 = 平均、自然勾配の道が座標によらないこと、EM の対数尤度が減らないこと、ジェインズのサイコロ（平均 4.5、λ ≈ 0.3710）と二分法の一致、α → ±1 の極限 = 2 つの KL、3 変数の分解の和、フィッシャー-ラオ距離 = 大円の長さ、などを照合しています。コイン 1 枚のエントロピーはシリーズ 6 の 01、双曲平面そのもの（ポアンカレ円板）はシリーズ 28 の 09、最適化の工夫（ニュートン法・Adam など）はシリーズ 49、クラスタリングとしての混合ガウス分布と EM はシリーズ 61 の 08、ボルツマン分布はシリーズ 55 の 09 で扱っています。
