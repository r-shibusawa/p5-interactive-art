コード集

確率分布を「点」と見ると、分布の集まりは曲がった空間になる。確率の三角形と KL ダイバージェンス、フィッシャー情報とクラメール-ラオの限界、双曲平面になる正規分布の族、指数型分布族の 2 つの座標、e と m の 2 種類のまっすぐ、ピタゴラスの定理と射影、ブレグマン・ダイバージェンス、自然勾配、EM 法、最大エントロピー、α-ダイバージェンス、相互情報量、球の上のフィッシャー-ラオ距離、音とカメラまで。どのスケッチもライブラリなしで本当に計算し、起動時の自己テストで答えを確かめています。

p5.js Web Editor を開く → ZIP でダウンロード

02エディタの sketch.js を全部消して貼り付け
03左上の ▶ で実行
