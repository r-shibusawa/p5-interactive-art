# シリーズ43：双対性 ─ p5.js コード集

数学のあちこちに現れる「裏返しても同じ」構造 ─ 双対性。点と直線、多面体の頂点と面、ボロノイとドロネー、線形計画の主問題と双対問題、凸関数とルジャンドル変換、AND と OR、流れとカット、時間と周波数。見た目はちがっても同じ骨組みを持つ対を、2D/3D のインタラクティブなスケッチで体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series43/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（13）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 双対が画面の外へ飛ぶ（01・07） | 原点が図形の外か辺の上。原点（白）か頂点をドラッグして原点を内側に入れる |
| LP の領域が消える・「実行可能解がない」（03〜05） | 係数を 0 にしすぎ。R でリセットしてから 1 つずつ変える |
| 最適値が一致しない（03） | 非有界か実行不能のとき。片方が非有界なら相手は実行不能（表示を読む） |
| 画面が固まる | 点を減らす（02・15 の母点、11 の `N`、12 の頂点数） |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

ボロノイ・ドロネーは簡単な O(n²) の方法（Bowyer–Watson 法と半平面の切り取り）、LP は 2 変数の頂点列挙で解いています。式は Boyd & Vandenberghe『Convex Optimization』、Chvátal『Linear Programming』と同じ形にしてあります。
