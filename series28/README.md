# シリーズ28：多様体 ─ p5.js コード集

どこを拡大しても平らに見えるのに、全体では曲がっている ─ それが多様体。球面・トーラス・双曲平面を舞台に、地図（チャート）、接平面、曲率、測地線、平行移動、ガウス＝ボネの定理までを 3D で回して体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series28/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 多くのスケッチは一番下に「3D の道具」などがあるので、必ず最後まで全部コピーする。🔊 音を使うスケッチ（13・14）は、実行したらまずキャンバスを1回クリック。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `makeSurface is not defined` / `pickUV is not defined` | 一番下の「3D の道具」までコピーできていない → 全部コピーし直す |
| クリックしても点が選べない | 面の上をクリックする（背景はドラッグで回すだけ）。面のふちぎりぎりは外れることがある |
| 測地線が途中で止まる | 球面の極の近くでは緯度経度の座標がこわれる（06 の説明）。出発の向きを少し変える |
| 画面が重い | 面の分割数（`makeSurface` の 72, 54 など）や 12 の `cs` を大きく、09 のタイル枚数を減らす |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

曲率・測地線などは差分と数値積分による近似計算です。式は微分幾何の教科書（小林昭七『曲線と曲面の微分幾何』、do Carmo『Differential Geometry of Curves and Surfaces』など）と同じ形にしてあります。
