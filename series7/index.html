音楽情報処理
コード集

音階・リズム・音色・メロディを数で扱う。テンポを聞き取り、調を当て、ルールで作曲する。音楽をコンピュータで分析・生成します。

p5.js Web Editor を開く → ZIP でダウンロード
01番号を開いて「コードをコピー」
02エディタの sketch.js を全部消して貼り付け
03左上の ▶ で実行
04音のスケッチは一番下の道具までコピーして、まずクリック
