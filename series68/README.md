# シリーズ68：神経回路網理論 ─ p5.js コード集

**ニューロンをつないだ網が「なぜ」学習できるのか** を理論で見る ― 神経回路網理論のワークショップ（110分）のコード集です。1 個のニューロン（パーセプトロンと収束定理、活性化関数、カバーの定理と線形分離の容量、万能近似）から始めて、学習のしくみ（計算グラフと誤差逆伝播、XOR を解く隠れ層、損失の地形、深さと初期化）、汎化（二重降下、正則化、畳み込みと等変性、再帰網の力学とリザバー計算）、連想記憶とエネルギー（ホップフィールド網、ボルツマンマシン）、そしてスパイクするニューロンの音とカメラ映像を学ぶパーセプトロンまで、どれも**ライブラリを使わずにゼロから実装して、定理や公式と答えが一致することを確かめる**スケッチです。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「神経回路網の道具」（活性化関数、連立 1 次方程式とリッジ回帰、小さなニューラルネット、グラフを描く道具、種つきの乱数、自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. 学習やシミュレーションは 1 フレームに少しずつ進めるので、画面は止まりません。右下の「自己テスト ✓」が計算の正しさの目印
6. 記号：入力 x、重み w、バイアス b（(x, 1) と 1 を足して w に含めることも）、活性化関数 f、損失 L、σ = シグモイド、ReLU = max(0, z)、ρ = スペクトル半径、E = エネルギー

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `seedRng is not defined` / `actF is not defined` | 一番下の「神経回路網の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 画面右下の「自己テスト」が ✗ になる | 道具や式を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 学習が進まない・損失が NaN | 学習率を小さくする。値はどこでもはさんでいる（clampv）ので、R でやり直せば元にもどる |
| 画面がカクカクする | 1 フレームの計算量（`STEPS_PER_FRAME` や `performance.now() - t0 < 8` の 8 ミリ秒）を小さくする |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

乱数はすべて種つき（mulberry32）なので、同じ種なら毎回同じ結果になります。パーセプトロンとノビコフの収束定理（R と γ はバイアスを含む (x, 1) の空間で測る）、カバーの関数計数定理と総当たりの線形分離判定、シグモイドの段・ReLU の折れ線による構成的な万能近似、スカラーの計算グラフと誤差逆伝播、2-2-1 のネットの XOR、損失の断面と主成分（べき乗法）、深いネットの分散の漸化式（数値積分）とランダムなネット、ランダム特徴の最小ノルム解とリッジ回帰、重み減衰・早期終了・ドロップアウト、循環境界の畳み込み、エコーステートネットワークとスペクトル半径、ヘッブ則のホップフィールド網とエネルギー、分配関数を数え上げる制限ボルツマンマシンと CD-1、漏れ積分発火ニューロンの正確な積分は、すべてゼロから実装しています。各スケッチは起動時の自己テストで、修正の回数 ≤ (R/γ)²、XOR で止まらないこと、微分 = 差分、C(N, d) = 総当たり・C(2d, d) = 2^(2d−1)、近似の誤差がニューロンとともに下がること、逆伝播 = 差分、XOR の損失 < 0.01 と隠れ層での線形分離、入れかえで損失が変わらないこと、漸化式 = シミュレーション（10% 以内）とヒーの初期化、二重降下の山が p ≈ n でリッジで消えること、ずらしの差 = 0、ρ < 1 で初期状態を忘れること、エネルギーが増えないことと固定点、確率の合計 = 1 と対数尤度の上昇、発火頻度 = 公式（2% 以内）などを照合しています。しきい値のニューロンはシリーズ 51 の 09、自己組織化マップはシリーズ 61 の 12、ネットを道具として使う Q 学習はシリーズ 63 の 11、アンサンブルはシリーズ 64 の 13、最適化法（勾配降下・Adam）の比較はシリーズ 17 の 12 とシリーズ 49 の 05 で扱っています。
