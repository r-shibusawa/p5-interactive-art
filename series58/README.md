# シリーズ58：クリフォード代数 ─ p5.js コード集

「ベクトルどうしの掛け算って何？」― 内積と外積をひとつにまとめた**幾何積**から、回転・反射・面積・体積・交わりを 1 つの代数（**幾何代数**）で計算するワークショップ（110分）のコード集です。ウェッジ積と二重ベクトル（向き付きの面）、2 次元の I² = −1 と複素数、鏡の反射 −n v n⁻¹ と 2 回の反射でできるローター、3 次元の回転と四元数、行列式とクラメルの公式、双対と交わり、符号 (p, q) で変わる代数、時空の代数のローレンツブースト、円を外積 1 つで表す共形幾何代数、角運動量 L = r∧p まで、どれも**本当に計算した**マルチベクトルで動いています。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series58/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「幾何代数の道具」（マルチベクトルの計算・比べるための行列や外積・自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. マルチベクトルは 2ⁿ 個の数の配列で、基底を「ビットマスク」で番号づけしています（n = 3 なら 0 = 1、1 = e1、2 = e2、3 = e12、4 = e3、5 = e13、6 = e23、7 = e123。e31 = −e13）。06・07・09 は 3D（WEBGL）で、ドラッグで視点を回せます

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `makeAlgebra is not defined` / `check is not defined` | 一番下の「幾何代数の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 画面右下の「自己テスト」が ✗ になる | 道具の中の式を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 3D（06・07・09）が小さい・見えない | ドラッグで回す、ホイールで拡大縮小。`scl` を変える |
| 万華鏡（04・15）の模様がにごる | 鏡の角度が 180°/k になっていない。K で角をそろえる（閉じないのは正しい計算結果） |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 は V でテスト画像に切りかえられる） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

マルチベクトルは 2ⁿ 個の数の配列で、幾何積は「基底ブレードのビットマスクの XOR が結果の基底、並べかえの入れかえ回数の偶奇が符号、同じ e_i が並んだら e_i² = ±1 を掛ける」という 1 つの規則で計算しています（同じコードで n = 5、32 成分まで動きます）。そこから外積 ∧、左縮約 ⌋、逆順 ã、次数の反転、双対 a I⁻¹、ノルム、ベルソルの逆元、二重ベクトルの指数関数（2 乗がスカラーなら閉じた式、そうでなければ級数）を作り、反射 −n v n⁻¹、ローターのサンドイッチ R v R̃、双対による交わりはすべてこの演算だけで求めています。各スケッチは起動時の自己テストで、e_i e_j = −e_j e_i と e_i² = 符号（n ≤ 5 のすべての (p, q)）、G(3)・Cl(1,3)・Cl(4,1) の結合法則、ab = a·b + a∧b、|a∧b| = |a||b| sin θ、2 回の反射 = 2α の回転行列、R v R̃ = ロドリゲスの回転行列と R R̃ = 1、偶数部分の四元数の関係、a × b = −I(a∧b)、a∧b∧c = det·I とクラメルの公式（ガウスの消去法と 1e-9 で一致）、meet の交線が両方の平面の上にあること、Cl(0,1) ≅ ℂ・Cl(0,2) ≅ ℍ・Cl(1,0) の j² = +1、ブーストの合成がラピディティの和で速度の合成式と一致、共形幾何代数の円の中心と半径 = 外心の公式、ケプラー運動で L = r∧p が保存されることなどを照合しています。

四元数と 3 次元の回転は [シリーズ 57](../series57/)、対称性と二面体群は [シリーズ 23](../series23/)、同次座標と射影幾何は [シリーズ 39](../series39/) でくわしく扱っています。
