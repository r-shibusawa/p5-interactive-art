ボロノイ図
コード集

いちばん近いのはどれ？ 平面を「最寄りの点」で塗り分けるボロノイ図。垂直二等分線・ドロネー三角形分割・掃引線での作り方から、ロイドの緩和と点描画、最大空円と経路計画、キリンの模様、音とカメラまで自分の手で動かします。

p5.js Web Editor を開く → ZIP でダウンロード
01番号を開いて「コードをコピー」
02エディタの sketch.js を全部消して貼り付け
03左上の ▶ で実行
04音のスケッチ（13・14）は一番下の道具までコピーして、まずクリック
