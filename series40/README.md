# シリーズ40：微分幾何学 ─ p5.js コード集

「曲がり方」を数で測る。平面曲線の曲率と接触円から始めて、空間曲線のフレネ標構、曲面の第一・第二基本形式とガウス曲率、測地線・平行移動・ガウス＝ボネの定理、極小曲面と曲率流、擬球の負曲率の世界までを、自分の手で動かして体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series40/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. ほとんどのスケッチは一番下に「曲面の道具」「3D の道具」（差分で曲率を計算する関数、メッシュを作る関数）があるので、**一番下まで全部コピー**する。🔊 音を使うスケッチ（13）は、実行したらまずキャンバスを1回クリック。📷 カメラ（15）はアドレスバーで許可する。3D のスケッチはドラッグで視点が回る

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `fundForms is not defined` / `gridMesh is not defined` | 一番下の「曲面の道具」「3D の道具」までコピーできていない → 全部コピーし直す |
| 3D の画面が真っ暗・何も見えない | ドラッグで視点を回す。`scaleF` を小さく。`createCanvas(..., WEBGL)` の `WEBGL` を消していないか確認 |
| κ や K がガタガタ・NaN になる | 点の間隔 `h` を大きく（差分はノイズに弱い）。曲面の分割 `nu`・`nv` を変える |
| 画面が固まる | 分割数（`nu`・`nv`・`nx`）を減らす。09 の `iters`、06 の `maxLen` を小さく |
| 曲面の裏側が真っ黒 | `gridMesh` は両面を作るので通常は出ない。自分でメッシュを作ったら裏面も足す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

曲率はすべて差分（有限差分）で数値計算しています。式は微分幾何の教科書（do Carmo『Differential Geometry of Curves and Surfaces』、小林昭七『曲線と曲面の微分幾何』など）と同じ形にしてあります。
