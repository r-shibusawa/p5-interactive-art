# シリーズ42：マトロイド理論 ─ p5.js コード集

「独立」を抽象化する。ベクトルの線形独立とグラフの「閉路なし」は同じ構造 ─ それがマトロイド。独立集合・基・サーキット・階数・閉包の公理から、貪欲法が必ず最適になる理由（マトロイド = 貪欲法がいつも正しい構造）、双対・マイナー・表現可能性・マトロイド交差までを、小さな台集合（8〜12 要素）を自分の手で動かして体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series42/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. 🔊 音を使うスケッチ（13）は、実行したらまずキャンバスを1回クリック。コードは一番下の「道具」まで全部コピーする。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| 「従属」のはずなのに独立と出る | 00・05 は小さな値を 0 とみなしている（`1e-6`）。ぴったり同じ直線に乗せるには格子（05）か数値を直接書く |
| 辺をクリックしても反応しない | 辺の真ん中あたりをクリック（14 px 以内）。ノードの上はドラッグになる |
| 画面が固まる・遅い | 全列挙は 2^（辺の数）。辺を 12〜15 本以下に（01 の `extraEdges`、06 の辺の本数、14 の `maxPts`） |
| `makeUF is not defined` | 一番下の「マトロイドの道具」までコピーできていない → 全部コピーし直す |
| `startAudio is not defined` | 一番下の「音を鳴らすための道具」までコピーできていない → 全部コピーし直す |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

台集合はすべて小さく（≤ 12 要素）してあるので、独立性は総当たりで確かめられます。用語と公理は Oxley『Matroid Theory』、Schrijver『Combinatorial Optimization』に合わせてあります。
