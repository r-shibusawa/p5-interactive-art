# シリーズ64：アンサンブル学習 ─ p5.js コード集

**1 つの賢いモデルより、ちがうモデルをたくさん組み合わせる** ― アンサンブル学習のワークショップ（110分）のコード集です。集合知と多様性予測定理、コンドルセの陪審定理、バイアスとバリアンス、相関のある平均の限界で「なぜうまくいくか」を確かめ、ちがう種類のモデルの投票、重み付き平均、スタッキング、専門家の混合で「組み合わせ方」を学び、マージンと 2 次の勾配ブースティング、ランダム化と多様性の測り方を深め、Isolation Forest の異常検知とアンサンブルで測る「自信のなさ」で使ってみて、最後は合唱とカメラの重み付き多数決まで。どれも**機械学習のライブラリを使わずにゼロから計算した**シミュレーションです。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series64/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. どのスケッチも一番下に「アンサンブル学習の道具」（種つきの乱数、k 近傍法・ロジスティック回帰・ナイーブベイズ・ニューラルネット・切り株、グラフ、自己テストなど）があるので、**一番下まで全部コピー**する。実行したらまずキャンバスを1回クリック（キー操作が届くように）。🔊 音を使うスケッチ（14）は**音量を小さめから**。📷 カメラ（15）はアドレスバーで許可する
5. 学習や木を育てる計算は 1 フレームに数ミリ秒ずつ進めるので、画面は止まりません。スライダーのあるスケッチ（00・01・03）はマウスでドラッグ
6. 記号：予測 f、正解 y、平均 f̄、分散 σ²、相関 ρ、重み w、マージン y·F(x)/Σα、勾配 g、ヘッセ h、正則化 λ・γ、異常スコア s

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `seedRng is not defined` / `fitBase is not defined` | 一番下の「アンサンブル学習の道具」までコピーできていない → 全部コピーし直す |
| キーを押しても反応しない | キャンバスを1回クリックしてからキーを押す |
| 画面右下の「自己テスト」が ✗ になる | 道具やアルゴリズムの式を書きかえた。コンソールでどの項目かを見る。コピーし直せば元どおり |
| 「学習中…」「計算中…」のまま | 数秒待つ（1 フレームに少しずつ計算している）。それでも進まないときはページを読み直す |
| 画面がカクカクする | 1 フレームの計算時間（`performance.now() - t0 < 6` の 6 ミリ秒）を小さくする |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可（15 はカメラがなくてもテスト画像で動く） |
| 音が大きすぎる | すぐに端末の音量を下げる。全体の音量は 0.2 以下（`MASTER`）。上げないこと |

乱数はすべて種つき（mulberry32）なので、同じ種なら毎回同じ結果になります。k 近傍法、ロジスティック回帰（ニュートン法と L2 正則化）、ガウスのナイーブベイズ、隠れ層 1 層のニューラルネット（手書きの誤差逆伝播と Adam）、重みつきの切り株、チェビシェフ多項式の最小 2 乗法、多数決とソフト投票、単体への射影と射影勾配法、5 分割の out-of-fold スタッキング、ソフトマックスのゲートの専門家の混合、マージンを記録するブースティング、2 次の勾配ブースティング（正則化つきの利得）、ランダム化した木と Extra Trees、Isolation Forest（c(n) の補正つき）、重み付き多数決はすべてゼロから実装しています。各スケッチは起動時に自己テストで、多様性予測定理（1e-9）、多数決の正解率の 2 項分布の和 = 総当たり、バイアス² + バリアンス = ノイズなしの誤差、相関のある平均の分散 = シミュレーション、射影勾配法の重み = 総当たりの最小、スタッキングの漏れ、専門家の混合の勾配 = 数値微分、指数損失の恒等式、利得の式 = 目的関数の直接計算、κ・Q・ρ の性質、c(n) = 2H(n − 1) − 2(n − 1)/n、アンビギュイティ分解、重み付き多数決のまちがいの上限などを照合しています。決定木そのもの・バギング・ランダムフォレスト・AdaBoost・勾配ブースティングの基本はシリーズ 62（決定木）、乗算型重み更新法はシリーズ 17 で扱っています。
