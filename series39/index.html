平行線は無限遠で交わる。透視図法の消失点から、同次座標と外積、ホモグラフィと複比、デザルグ・パップス・パスカルの定理、有限射影平面、ピンホールカメラまで。点を動かしながら「射影しても変わらないもの」を自分の手で確かめます。

p5.js Web Editor を開く → ZIP でダウンロード
01番号を開いて「コードをコピー」
02エディタの sketch.js を全部消して貼り付け
03左上の ▶ で実行
04どのスケッチも一番下の道具までコピー。音（13）はまずクリック
