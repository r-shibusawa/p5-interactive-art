# シリーズ39：射影幾何学 ─ p5.js コード集

「平行線は無限遠で交わる」。透視図法の消失点から出発して、同次座標・外積・ホモグラフィ・複比、デザルグ／パップス／パスカルの古典定理、有限射影平面、ピンホールカメラまでを、自分の手で動かして体験するワークショップ（110分）のコード集です。
[p5.js Web Editor](https://editor.p5js.org/) にコピー＆ペーストするだけで動きます。

## 🌐 コード集サイト

**https://r-shibusawa.github.io/p5-interactive-art/series39/**

## 使い方（p5.js Web Editor）

1. https://editor.p5js.org/ を開く
2. `sketch.js` の中身を全部消して（`Ctrl/⌘ + A` → `Delete`）、コードを貼り付ける
3. 左上の ▶（実行）ボタンを押す
4. ほとんどのスケッチは一番下に「射影幾何の道具」（外積・ホモグラフィの関数）があるので、**一番下まで全部コピー**する。🔊 音を使うスケッチ（13）は、実行したらまずキャンバスを1回クリック。📷 カメラ（15）はアドレスバーで許可する

## 困ったときは

| 症状 | 解決法 |
|---|---|
| `hCross is not defined` / `homographyFrom4 is not defined` | 一番下の「射影幾何の道具」までコピーできていない → 全部コピーし直す |
| 交点が画面に出ない | 平行に近くて無限遠に飛んでいる。画面のふちの矢印を探す（向かい合う 2 つの矢印は同じ 1 点） |
| 「4 点がつぶれています」 | 四角形の角が重なっている／3 点が一直線。R でリセット |
| 行列式が 0 にならない | 1e-4 くらいまでは計算誤差で正常。点を重ねると大きくなる |
| 画面が固まる・遅い | 15 の `vw, vh` や出力の大きさを小さく。05 の円のサンプル数（720）を減らす |
| 音が出ない・カメラが動かない | キャンバスを1回クリック ／ アドレスバーの鍵マークで許可 |

点と直線は同次座標 `[x, y, w]` で表し、直線は 2 点の外積、交点は 2 直線の外積で求めています。ホモグラフィは 4 点対応からの 8×8 連立方程式をガウスの消去法で解いています（Hartley & Zisserman『Multiple View Geometry』、Richter-Gebert『Perspectives on Projective Geometry』と同じ流儀）。
